## RISKS:

### Technical Risks

1. **localStorage Schema Unknown**
   - Cannot see JavaScript code with contact data structure
   - Risk: Import may create contacts with wrong schema, breaking existing display logic
   - Mitigation: Must inspect existing localStorage structure before implementation

2. **Duplicate Detection Logic Undefined**
   - Task says "skip duplicates" but doesn't specify duplicate criteria
   - Risk: May skip valid contacts or allow duplicates
   - Common strategies: email-based, name+company combination, or ID-based
   - Need to determine existing duplicate detection strategy (if any)

3. **CSV Parsing Edge Cases**
   - Quoted fields with commas, newlines within fields, inconsistent quote escaping
   - Risk: Naive split-by-comma parsing will break on complex CSVs
   - Mitigation: Need robust CSV parsing logic (though task says "no external libraries")

4. **File Size Limits**
   - FileReader loads entire file into memory
   - Risk: Large CSV files (>10MB) could freeze browser
   - No file size validation mentioned in task

5. **Character Encoding**
   - CSV may have non-UTF-8 encoding (e.g., Latin-1, Windows-1252)
   - Risk: Special characters may display incorrectly
   - FileReader defaults to UTF-8

6. **Column Detection Ambiguity**
   - Task says detect "name/first/last" but doesn't specify priority
   - Risk: CSV with both "name" and "first"+"last" columns - which to use?
   - Need decision rule for conflicting columns

7. **Empty Field Handling**
   - Task says skip rows where "name AND company are both empty"
   - Risk: What if CSV has first/last but no "name" column? Does empty first+last count?
   - Need clear definition of "empty" (null, empty string, whitespace-only?)

8. **Modal Accessibility**
   - File input triggers aren't keyboard accessible by default
   - Risk: Screen reader users or keyboard-only users cannot import
   - Need to ensure file input is focusable and has proper labeling

9. **localStorage Quota Exceeded**
   - Importing many contacts could exceed 5-10MB localStorage limit
   - Risk: Import fails silently or with unhelpful error
   - No quota checking mentioned in task

10. **Existing Contact Display Refresh**
    - After import, need to trigger re-render of contact list
    - Risk: New contacts don't appear until page reload
    - Need to call existing render function after import

### UI/UX Risks

1. **Button Placement Unclear**
   - Task says "on the contacts page" but doesn't specify exact location
   - Header actions seems logical, but could also be above contact list
   - Risk: Poor placement could disrupt existing layout

2. **Preview Modal Size**
   - Showing 5 rows + column mapping could be tall
   - Risk: Modal may not fit on mobile viewports
   - Existing modal has max-height: 90vh, but content could still be cramped

3. **No Loading State**
   - Large CSV parsing is synchronous and could take time
   - Risk: UI appears frozen during processing
   - No loading spinner or progress indicator specified

4. **No Error Handling UI**
   - If CSV is malformed, what error message to show?
   - Risk: Silent failures or browser console errors only
   - Need error modal or inline error message

5. **Column Mapping Non-Obvious**
   - User may not understand detected mapping
   - Risk: User imports with wrong column assignments
   - Preview should clearly show which CSV columns map to which contact fields
