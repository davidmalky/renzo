## RISKS:

### Performance Risks:
1. **Large log table rendering** - Rendering 1000+ activity log rows could cause performance issues
   - *Mitigation*: Implement pagination or virtual scrolling
2. **30-second auto-refresh** - Frequent DOM updates may cause UI jank
   - *Mitigation*: Only refresh if view is active and sync is running; use requestAnimationFrame
3. **localStorage size limits** - Activity logs could exceed 5-10MB quota
   - *Mitigation*: Implement log rotation, keep only last 30 days or 1000 records

### Data Consistency Risks:
4. **Race conditions** - Auto-refresh may conflict with user interactions (filtering, expanding rows)
   - *Mitigation*: Debounce refresh, preserve UI state (scroll position, expanded rows)
5. **Sync state synchronization** - Multiple tabs may show inconsistent sync status
   - *Mitigation*: Use localStorage events or single source of truth
6. **Timestamp accuracy** - Client-side timestamps may not match Salesforce server time
   - *Mitigation*: Store both local and server timestamps if available

### UI/UX Risks:
7. **Modal conflicts** - Existing modal system may conflict with new toast notifications
   - *Mitigation*: Use different z-index layers (modals: 1000, toasts: 1100)
8. **Mobile responsiveness** - Fixed sidebar and wide tables may break on small screens
   - *Mitigation*: Test log table with horizontal scroll or card layout on mobile
9. **Expandable rows accessibility** - Keyboard navigation and screen reader support
   - *Mitigation*: Add ARIA attributes, keyboard event handlers

### Integration Risks:
10. **Missing Salesforce API** - No actual Salesforce sync logic visible in HTML
    - *Mitigation*: API calls must be implemented in separate JS file
11. **Authentication state** - Sync operations may fail if Salesforce token expires
    - *Mitigation*: Handle 401 errors, show re-authentication prompt
12. **Field mapping dependencies** - Activity log needs to understand existing field mappings
    - *Mitigation*: Load field mapping config from localStorage

### Security Risks:
13. **CSP violations** - Toast notifications with inline styles may violate CSP
    - *Mitigation*: Use class-based styling only
14. **XSS in log data** - Salesforce field values could contain malicious scripts
    - *Mitigation*: Sanitize all user-generated content, use textContent not innerHTML
