# TECHNICAL SPECIFICATION: Full Mobile Responsive Layout Rework

## OVERVIEW
Transform the desktop-only sidebar navigation into a responsive mobile layout with bottom navigation bar, top header, and mobile-optimized components. At 768px breakpoint, sidebar becomes fixed bottom nav with emoji icons, add fixed top header, convert contacts table to card layout, and adjust modal behavior. All changes implemented via CSS and minimal JS modifications to existing render functions.

## VIEWS
- **Desktop Layout**: Unchanged - sidebar left, main content right
- **Mobile Layout (≤768px)**: Fixed bottom nav bar (56px height), fixed top header (52px height), main content with adjusted padding
- **mobileHeader**: New fixed top bar showing logo, user info, logout icon (only visible on mobile)
- **Bottom Nav Bar**: Transformed sidebar with 8 horizontal nav items, emoji icons above labels
- **Contacts Card View**: Alternative to table for mobile, card-based list with badges and actions
- **Mobile Modals**: Bottom sheet style with rounded top corners

## FUNCTIONS
- **renderContacts() [MODIFY]**: 
  1. Check `window.innerWidth <= 768`
  2. If true, call `renderContactsCards()` instead of table rendering
  3. If false, proceed with existing table rendering logic
  4. Preserve all existing filtering/sorting logic

- **renderContactsCards() [NEW]**:
  1. Create container div with class `.contacts-cards-mobile`
  2. For each contact, create card div with class `.contact-card-mobile`
  3. Build card HTML: name + priority badge in header, company text, tier badge, status badge, message button
  4. Append cards to container
  5. Return container HTML or insert into DOM (match existing pattern)
  6. Add click handler for message button

- **createMobileHeader() [NEW]**:
  1. Check if `#mobileHeader` already exists, return if so
  2. Create div with id `mobileHeader`
  3. Insert Renzo logo (clone from `.sidebar-logo` or use text)
  4. Insert user display name from `.sidebar-user` text content
  5. Insert logout button as icon (🚪 or use existing logout handler)
  6. Insert as first child of `body`
  7. Called on DOMContentLoaded

- **initMobileLayout() [NEW]**:
  1. Call `createMobileHeader()`
  2. Add window resize listener
  3. On resize, check width and re-render contacts if crossing 768px threshold
  4. Debounce resize handler (250ms)

## ERRORS
- **Resize thrashing**: Debounce window resize listener to prevent excessive re-renders
- **Missing elements**: Check for existence of `.sidebar-user` and `.sidebar-logo` before cloning content
- **Empty contacts**: Handle zero contacts in card view with empty state message
- **Nav item mismatch**: Verify all 8 nav items have `data-view` attributes matching emoji mapping
- **CSS variable undefined**: Ensure `--green-mid-rgb` is defined or fall back to rgba conversion
- **Modal not found**: Check if modal classes exist before applying mobile styles
- **Touch target too small**: Audit all interactive elements to meet 44px minimum
- **Breakpoint flicker**: Add `transition: none` during resize to prevent animation artifacts
- **Badge overflow**: Handle long badge text with `overflow: hidden` and `text-overflow: ellipsis`
- **Z-index conflicts**: Ensure mobile header (500) and bottom nav (500) don't conflict with modals (typically 1000+)
