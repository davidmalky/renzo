## ERRORS

### Timeout Errors (TimeoutError, AbortError)
- Trigger: Fetch exceeds 30 seconds
- Handling: Show toast "Request timed out — try again" with type 'error'
- UI cleanup: Re-enable button, hide loading states (aiLoading if in generateMsg)
- User action: User can retry operation

### Network/Server Errors
- Trigger: Connection failure, 4xx/5xx responses, or other exceptions
- Handling: Show toast "Error: [e.message]" with type 'error'
- UI cleanup: Re-enable button, hide loading states
- User action: User sees specific error and can retry
