# TECHNICAL SPECIFICATION: CSV Import for Renzo Contacts

## OVERVIEW
Add CSV import capability to existing contacts page using vanilla JavaScript FileReader API. Feature includes file selection button, automatic column detection for name/company/email/phone fields, preview modal showing first 5 rows with detected mappings, and import execution with duplicate detection. All existing contact functionality remains untouched.

## FUNCTIONS

**initCSVImport()**:
- Attach event listener to Import CSV button
- Create hidden file input element (accept=".csv")
- Trigger file input on button click
- Listen for file selection change event
- Call handleFileSelect(file) when file chosen

**handleFileSelect(file)**:
- Validate file extension is .csv
- If invalid: show error toast "Please select a CSV file"
- Create FileReader instance
- Set reader.onload to call parseCSV(result)
- Call reader.readAsText(file)

**parseCSV(csvText)**:
- Split text by newline (\n), trim each line
- Extract headers from first row, split by comma
- Parse remaining rows: split by comma, handle quoted values
- Return object: { headers: [], rows: [[]], totalRows: number }
- Handle edge case: empty file returns null

**detectColumns(headers)**:
- Create mapping object: { name: null, company: null, email: null, phone: null }
- For each header (case-insensitive):
  - Match "name", "first", "last", "full" → name field
  - Match "company", "organization", "org" → company field
  - Match "email", "e-mail", "mail" → email field
  - Match "phone", "telephone", "tel", "mobile" → phone field
- Store matched header indices
- Return mapping with column indices

**showPreviewModal(csvData, columnMapping)**:
- Build modal HTML dynamically
- Column mapping section: display 4 rows with labels and detected columns
- If column not detected, show "Not detected" in muted text
- Preview table: loop first 5 rows from csvData.rows
- Display all columns in table for context
- Highlight detected columns with --forest-green-light background
- Attach event listeners: close modal on cancel/X, confirmImport on confirm button

**confirmImport(csvData, columnMapping)**:
- Get existing contacts from localStorage (key: "renzo_contacts")
- Parse JSON or initialize empty array
- Create Set of existing contact keys for duplicate detection: "name|company"
- Loop through all csvData.rows:
  - Extract values using columnMapping indices
  - Clean/trim each value
  - Skip if name AND company are both empty
  - Create normalized key: `${name}|${company}`.toLowerCase()
  - If key exists in Set: increment skipped counter, continue
  - Add key to Set
  - Create contact object: { id: Date.now() + random, name, company, email, phone, createdAt: Date.now() }
  - Push to contacts array
  - Increment imported counter
- Save updated contacts to localStorage
- Close preview modal
- Show result toast with imported/skipped counts
- Refresh contacts display by calling existing renderContacts() function

**closeCSVModal()**:
- Remove .active class from modal overlay
- Remove modal HTML from DOM after 300ms transition

**showToast(message, duration)**:
- Create toast element with message
- Append to document body
- Position fixed top: 20px, left: 50%, transform: translateX(-50%)
- Add show class for fade-in animation
- setTimeout to remove after duration (default 4000ms)

## API

**No external API calls required**

**localStorage API**:
- GET: localStorage.getItem("renzo_contacts") - retrieve existing contacts
- SET: localStorage.setItem("renzo_contacts", JSON.stringify(contacts)) - save updated contacts

**FileReader API**:
- Method: readAsText(file)
- Event: onload - triggers when file read complete
- Response: event.target.result contains CSV text content

## ERRORS

**Invalid file type**:
- User selects non-CSV file
- Show error toast: "Please select a CSV file"
- Reset file input value

**Empty CSV file**:
- File contains no data rows
- Show error toast: "CSV file is empty"
- Do not open preview modal

**Malformed CSV**:
- Parsing errors (unclosed quotes, inconsistent columns)
- Attempt to parse row-by-row, skip malformed rows
- Show warning in preview: "Some rows could not be parsed"

**No columns detected**:
- CSV headers don't match any known patterns
- Still show preview modal
- Display "Not detected" for all fields
- User can still import (all fields will be empty)

**localStorage quota exceeded**:
- Try-catch around localStorage.setItem
- If quota exceeded: show error toast "Storage limit reached. Cannot import contacts."
- Rollback: do not modify existing contacts

**Duplicate detection edge case**:
- Both name and company empty: skip row (already handled in logic)
- Normalize keys to lowercase for case-insensitive matching
- Trim whitespace before comparison

**File read error**:
- FileReader onerror event
- Show error toast: "Failed to read file. Please try again."

**Modal interaction errors**:
- User closes modal during import: cancel operation
- Multiple rapid clicks: disable confirm button after first click
