# TECHNICAL SPECIFICATION: Contact Sync Dashboard & Activity Log

## OVERVIEW
Build a comprehensive sync monitoring dashboard as a new view within the Integrations section. The SyncActivityView provides real-time sync status monitoring, detailed activity logging with field-level change tracking, error management, and manual sync controls. The system auto-refreshes during active syncs, displays progress indicators, and allows granular filtering and export of sync history with retry capabilities for failed records.

## VIEWS

- **SyncActivityView**: Main container view (`.view#syncActivityView`) displaying complete sync monitoring interface with status overview, progress tracking, activity log, filters, and statistics
- **SyncStatusOverviewCard**: Top card showing last sync timestamp, total contacts synced, health indicator (green/yellow/red dot based on error rate <5%/5-15%/>15%), and manual 'Sync Now' button
- **RealtimeProgressIndicator**: Collapsible progress section with animated progress bar, operation description text, records counter (processed/total), elapsed time, and cancel button
- **ActivityLogTable**: Scrollable table with fixed header, expandable rows showing timestamp, operation type badge, Salesforce ID link, Renzo contact name, direction arrow icon, status badge, and expand toggle
- **ActivityLogRowDetails**: Expanded row content displaying field-by-field changes in two-column comparison (before/after), conflict indicators, error messages, and retry button for failed records
- **FilterControlsBar**: Horizontal bar with date range picker (start/end inputs), status multi-select dropdown (all/success/failed/conflict), operation type filter, and 'Clear Filters' button
- **ErrorSummarySection**: Collapsible section with error type cards showing error name, count badge, description, and resolution suggestion text
- **SyncStatisticsCards**: Four-card grid displaying: total syncs (30-day count with trend indicator), average duration (seconds with comparison to previous period), error rate (percentage with status color), last successful sync (relative timestamp)
- **ExportSyncLogButton**: Action button triggering CSV download of filtered activity log with all visible columns and expanded details

## FUNCTIONS

- **initializeSyncActivityView()**: Sets up view on load by attaching event listeners to sidebar nav item (#navSyncActivity), initializing auto-refresh interval (30s when sync active), loading initial sync status via fetchSyncStatus(), populating activity log with fetchActivityLog(), calculating and displaying statistics via calculateSyncStatistics(), setting up filter event handlers, and restoring previous filter state from sessionStorage
- **fetchSyncStatus()**: Makes GET request to /api/salesforce/sync/status, receives {isActive, lastSync, totalSynced, errorRate, currentOperation, progress}, updates SyncStatusOverviewCard health indicator color based on errorRate thresholds, displays lastSync in relative time format, shows/hides progress indicator based on isActive, returns status object for other functions
- **startManualSync()**: Triggered by 'Sync Now' button click, disables button and shows spinner, sends POST to /api/salesforce/sync/start with empty body, on 202 response shows success toast "Sync started", enables auto-refresh, updates UI to show progress indicator, on error shows error toast with message, re-enables button
- **pollSyncProgress()**: Called every 2 seconds during active sync, fetches GET /api/salesforce/sync/progress returning {processed, total, currentOperation, elapsedSeconds, estimatedRemaining}, updates progress bar width percentage (processed/total * 100), updates counter text "247/500 contacts", updates operation description, updates elapsed time display, stops polling when progress reaches 100%
- **fetchActivityLog(filters)**: Accepts filters object {dateStart, dateEnd, status[], operationType[], page, limit}, constructs query string, sends GET to /api/salesforce/sync/activity with params, receives {activities: [{id, timestamp, operationType, salesforceId, renzoContactName, direction, status, errorMessage, fieldChanges: [{field, oldValue, newValue, conflict}]}], total, page, pageSize}, renders activities into ActivityLogTable rows, updates pagination controls, stores current filters in sessionStorage
- **renderActivityLogRow(activity)**: Creates table row element with cells for formatted timestamp (local time), operation type badge with icon (initial-sync/update/delete/error), clickable Salesforce ID (links to SF record), Renzo contact name (links to contact detail), direction icon (right arrow for SF→Renzo, left for Renzo→SF, both for bidirectional), status badge with appropriate class, expand icon button, attaches click handler to expand row details, returns row element
- **expandActivityLogRow(activityId)**: Triggered by expand icon click, fetches detailed record if not cached via GET /api/salesforce/sync/activity/{activityId}/details, creates row details element with field change comparison table, inserts after clicked row, adds .expanded class, updates icon to collapse state, stores expanded state to prevent duplicate fetches
- **collapseActivityLogRow(activityId)**: Removes .expanded class from row details, slides up animation (CSS transition), removes row details element from DOM after animation, updates expand icon back to default state
- **renderFieldChanges(fieldChanges)**: Accepts array of field change objects, creates two-column comparison table with headers "Previous Value" and "New Value", iterates fieldChanges to create rows with field name, old value (formatted based on type), new value (formatted), highlights conflicts with yellow background and conflict icon, returns formatted table element
- **retryFailedRecord(activityId)**: Triggered by retry button in expanded row, shows confirmation modal "Retry sync for this record?", on confirm sends POST to /api/salesforce/sync/retry with {activityId}, on success shows toast "Retry initiated", updates activity log row status to "retrying", triggers fetchActivityLog() to refresh after 3 seconds, on error shows error toast with specific message
- **applyFilters()**: Collects values from all filter controls (date range inputs, status checkboxes, operation type select), validates date range (start < end), constructs filters object, calls fetchActivityLog(filters) to refresh table, updates URL query params to reflect filters, shows "No results" message if filtered data is empty, animates table refresh with fade transition
- **clearFilters()**: Resets all filter controls to default values (clear dates, check all statuses, reset operation type), removes URL query params, calls fetchActivityLog() with empty filters, clears sessionStorage filter state, shows success toast "Filters cleared"
- **calculateSyncStatistics()**: Fetches GET /api/salesforce/sync/statistics returning {last30Days: {total, avgDuration, errorRate, trend}, lastSuccessful}, calculates trend indicators (up/down/neutral based on comparison to previous 30-day period), formats avgDuration to human-readable (e.g., "2.3 seconds"), formats error rate as percentage with one decimal, formats lastSuccessful as relative time ("2 hours ago"), updates SyncStatisticsCards with calculated values and trend icons
- **updateSyncStatisticsUI(statistics)**: Accepts statistics object, updates each stat card's .stat-value with formatted number, updates .stat-delta with trend indicator and percentage change, applies color classes (.positive, .negative, .neutral) based on metric type, animates value changes with count-up effect for numbers, updates lastSuccessful timestamp
- **exportSyncLog()**: Triggered by export button, shows loading spinner on button, collects current filter state, sends GET to /api/salesforce/sync/export with filter params, expects blob response (CSV), creates temporary download link, sets filename "sync-activity-log-{timestamp}.csv", triggers click to download, removes temporary link, shows success toast "Export complete", hides spinner
- **generateCSVContent(activities)**: Accepts activities array, creates CSV header row with column names, iterates activities to create data rows with quoted fields (handles commas in values), formats timestamps to ISO string, flattens field changes into summary column, escapes special characters, returns complete CSV string
- **showSyncCompleteNotification(syncResult)**: Triggered by sync completion webhook/event, receives {status, recordsSynced, errors[], duration}, displays toast notification with status icon (success/warning/error), shows summary "Synced 247 contacts in 12 seconds", includes error count if present with link to error summary section, auto-dismisses after 8 seconds for success or remains for errors, plays notification sound
- **showSyncErrorNotification(error)**: Displays persistent error toast with error icon, error message text, "View Details" button linking to error summary, "Retry" button triggering startManualSync(), "Dismiss" button, does not auto-dismiss, logs error to console for debugging
- **startAutoRefresh()**: Starts setInterval calling fetchSyncStatus() and fetchActivityLog() every 30 seconds, stores interval ID in component state, only runs when sync is active (checked via isActive flag), stops when sync completes or view unmounted, updates last refresh timestamp display
- **stopAutoRefresh()**: Clears stored interval ID, updates UI to show "Auto-refresh paused", provides manual refresh button to restart polling
- **formatTimestamp(isoString)**: Converts ISO timestamp to local timezone, returns formatted string "Jan 15, 2025 2:30 PM", uses Intl.DateTimeFormat for localization
- **formatRelativeTime(isoString)**: Calculates time difference from now, returns human-readable relative time ("2 minutes ago", "3 hours ago", "2 days ago"), updates every minute for recent timestamps
- **formatDuration(seconds)**: Converts seconds to formatted duration string, uses minutes and seconds for <1 hour ("2m 34s"), uses hours and minutes for longer durations ("1h 15m")
- **getHealthIndicatorColor(errorRate)**: Accepts error rate decimal, returns color class string: "green" for <0.05, "yellow" for 0.05-0.15, "red" for >0.15, used to style health indicator dot
- **getOperationTypeIcon(operationType)**: Returns icon class string based on operation type: "sync-icon" for initial-sync, "update-icon" for update, "delete-icon" for delete, "error-icon" for error
- **getStatusBadgeClass(status)**: Returns CSS class string based on status: "status-badge success" for success, "status-badge error" for failed, "status-badge warning" for conflict, "status-badge info" for retrying/pending
- **validateDateRange(startDate, endDate)**: Checks if dates are valid, start < end, end not in future, returns {valid: boolean, error: string}, used before applying filters
- **handleSyncCancellation()**: Triggered by cancel button on progress indicator, shows confirmation modal "Cancel ongoing sync?", on confirm sends POST to /api/salesforce/sync/cancel, updates UI to show "Cancelling..." status, on completion shows toast "Sync cancelled", refreshes activity log to show partial results
- **handlePaginationClick(page)**: Updates current page number in state, calls fetchActivityLog with new page parameter, scrolls table to top, updates pagination button states (disabled for current page), updates URL query param
- **loadMoreActivities()**: For infinite scroll implementation (if paginated), detects scroll to bottom of table, fetches next page with fetchActivityLog({page: currentPage+1, append: true}), appends new activities to existing table, shows loading spinner during fetch
- **setupEventListeners()**: Attaches all event listeners including: sync now button click, filter control changes (debounced), export button click, pagination clicks, expand/collapse row clicks, retry button clicks, cancel sync button click, date range validation on blur, sets up keyboard shortcuts (R for refresh, E for export), returns cleanup function
- **cleanupView()**: Called when navigating away from view, stops auto-refresh interval, removes all event listeners, clears sessionStorage if needed, cancels pending fetch requests, resets component state

## DATA

- **syncStatus**: Object stored in component state {isActive: boolean, lastSync: ISO timestamp string, totalSynced: number, errorRate: decimal 0-1, currentOperation: string, progress: {processed: number, total: number}, elapsedSeconds: number} - represents current sync state
- **activityLog**: Array of activity objects [{id: UUID, timestamp: ISO string, operationType: enum('initial-sync', 'update', 'delete', 'error'), salesforceId: string (18-char SF ID), renzoContactId: UUID, renzoContactName: string, direction: enum('sf-to-renzo', 'renzo-to-sf', 'bidirectional'), status: enum('success', 'failed', 'conflict', 'pending', 'retrying'), errorMessage: string or null, fieldChanges: array, retryCount: number}] - stores activity history with pagination
- **fieldChanges**: Array within each activity [{field: string (field name), oldValue: any (JSON serialized), newValue: any (JSON serialized), conflict: boolean, dataType: string (text/date/number/picklist)}] - detailed field-level changes
- **filterState**: Object {dateStart: ISO string or null, dateEnd: ISO string or null, statuses: array of status enums, operationTypes: array of operation type enums, page: number, limit: number} - stored in sessionStorage for persistence
- **syncStatistics**: Object {last30Days: {total: number, avgDuration: number (seconds), errorRate: decimal, trend: number (percentage change)}, lastSuccessful: ISO string} - cached statistics data
- **expandedRows**: Set of activity IDs currently expanded - tracks UI state
- **autoRefreshIntervalId**: Number storing setInterval ID for cleanup
- **cachedActivityDetails**: Map of activityId to full detail objects - prevents redundant API calls
- **csvExportData**: Temporary blob data for download trigger
- **pendingRequests**: Array of AbortController instances for cancellable fetch requests

## API

- **GET /api/salesforce/sync/status**: Retrieves current sync status; no payload; returns {isActive: bool, lastSync: ISO, totalSynced: int, errorRate: float, currentOperation: string, progress: {processed: int, total: int}}; handles 200 success by updating UI state, 500 error shows error toast and retries after 5s
- **POST /api/salesforce/sync/start**: Initiates manual sync; payload {}; returns {syncId: UUID, message: string}; handles 202 accepted by enabling progress polling, 409 conflict (sync already running) shows warning toast, 500 error shows error message
- **GET /api/salesforce/sync/progress**: Polls active sync progress; query params {syncId: UUID}; returns {processed: int, total: int, currentOperation: string, elapsedSeconds: int, estimatedRemaining: int}; handles 200 by updating progress bar, 404 means sync completed (stop polling), 500 retries after 2s
- **POST /api/salesforce/sync/cancel**: Cancels active sync; payload {syncId: UUID}; returns {message: string, partialResults: {synced: int, failed: int}}; handles 200 by stopping progress and refreshing log, 404 if no active sync, 500 shows error
- **GET /api/salesforce/sync/activity**: Fetches activity log with filtering; query params {dateStart: ISO, dateEnd: ISO, status: comma-separated, operationType: comma-separated, page: int, limit: int, sortBy: string, sortOrder: asc/desc}; returns {activities: array, total: int, page: int, pageSize: int, hasMore: bool}; handles 200 by rendering table, 400 validation error shows field-specific errors, 500 retries
- **GET /api/salesforce/sync/activity/{activityId}/details**: Fetches full detail for single activity; path param activityId; returns {id: UUID, ...all activity fields, fieldChanges: full array, metadata: {createdBy: string, apiVersion: string}}; handles 200 by rendering expanded row, 404 shows "Record not found", 500 shows error
- **POST /api/salesforce/sync/retry**: Retries failed sync record; payload {activityId: UUID, options: {force: bool}}; returns {newActivityId: UUID, status: string}; handles 202 by showing retry initiated message, 400 if record cannot be retried (shows reason), 404 if activity not found, 500 shows error
- **GET /api/salesforce/sync/statistics**: Fetches sync statistics; query params {period: '30d' | '7d' | '24h'}; returns {last30Days: {total: int, avgDuration: float, errorRate: float, trend: float}, lastSuccessful: ISO, topErrors: [{type: string, count: int, suggestion: string}]}; handles 200 by updating statistics cards, 500 uses cached data if available
- **GET /api/salesforce/sync/export**: Exports filtered activity log as CSV; query params same as activity endpoint; returns blob (text/csv); handles 200 by triggering download, 400 validation error, 413 if export too large (shows message to narrow filters), 500 shows error
- **GET /api/salesforce/sync/errors/summary**: Fetches error summary for current period; query params {dateStart: ISO, dateEnd: ISO}; returns {errors: [{type: string, count: int, description: string, resolution: string, affectedRecords: int}], totalErrors: int}; handles 200 by rendering error summary section, 500 shows fallback message

## ERRORS

- **Network failure during status fetch**: Show toast "Unable to connect to server. Retrying...", retry with exponential backoff (2s, 4s, 8s), after 3 failures show persistent error banner with manual retry button, log error to console with network details
- **Sync already in progress (409)**: Show warning toast "Sync already running. Please wait for completion.", disable sync now button, ensure progress indicator is visible, poll for existing sync status
- **Invalid date range in filters**: Show inline validation error below date inputs "Start date must be before end date", highlight inputs with red border, prevent filter application until corrected, clear error on valid input
- **Activity log fetch returns empty results**: Show empty state message "No sync activity found for selected filters" with illustration, display "Clear filters" button, suggest broadening date range
- **Export file too large (413)**: Show modal "Export too large. Please narrow your date range or filters to reduce results.", provide suggestion "Try limiting to last 7 days", disable export button until filters changed
- **Failed to load activity details (404)**: Show toast "Activity record no longer available", collapse expanded row, remove expand icon from that row, refresh activity log in background
- **Retry API returns 400 non-retryable**: Show modal explaining why retry not possible (e.g., "Record deleted in Salesforce"), provide link to documentation, option to dismiss error from log
- **Sync cancellation fails**: Show error toast "Unable to cancel sync. It may have already completed.", refresh sync status immediately, log error details
- **Statistics calculation error**: Use fallback values (0 for counts, "N/A" for averages), show warning icon next to affected stat card with tooltip "Unable to calculate this metric", continue displaying other statistics
- **CSV generation timeout**: Show progress modal "Preparing export, this may take a moment...", if exceeds 30s show error "Export timed out. Try reducing date range.", offer to email report instead
- **WebSocket connection failure for live updates**: Fall back to polling mode automatically, show info toast "Live updates unavailable. Using polling mode.", continue functionality without real-time updates
- **Session expired during sync**: Show modal "Session expired. Please log in again.", pause sync operations, redirect to login with return URL to sync dashboard, preserve filter state in URL params
- **Insufficient permissions**: Show error message "You don't have permission to view sync activity", display contact administrator message, hide action buttons (sync now, retry, export)
