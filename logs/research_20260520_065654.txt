## RISKS:

### Technical Risks
1. **localStorage Limits**: Storing complex mapping configurations may exceed 5-10MB limits
2. **Schema API Performance**: Dynamic Salesforce field fetching could be slow; needs caching strategy
3. **Circular Dependencies**: Bidirectional mappings may create infinite loops if not properly validated
4. **JavaScript Eval Security**: Custom function editor requires sandboxed execution to prevent XSS
5. **Complex Validation Logic**: Real-time validation of formulas and transformations may impact performance
6. **Modal Nesting**: Formula/picklist builders within main modal may cause z-index conflicts
7. **Data Type Compatibility Matrix**: Need comprehensive type mapping logic (Salesforce ↔ Renzo types)

### UI/UX Risks
8. **Modal Overload**: Too many configuration options may overwhelm users; consider progressive disclosure
9. **Mobile Responsiveness**: Complex table with many columns will be difficult on small screens
10. **Dropdown Performance**: Large field lists (500+ fields) may cause dropdown lag
11. **Formula Builder Complexity**: Visual formula builder may be harder to use than text input for power users

### Data Integrity Risks
12. **Mapping Conflicts**: Multiple mappings to same destination field need conflict detection
13. **Orphaned Mappings**: Deleted Salesforce fields will break existing mappings; need cleanup strategy
14. **Version Control**: No backup/restore mechanism for mapping configurations
15. **Test Data Accuracy**: Preview transformations may not catch all edge cases

### Integration Risks
16. **Schema Changes**: Salesforce schema updates may invalidate existing mappings
17. **API Rate Limits**: Frequent schema API calls for validation may hit Salesforce rate limits
18. **Transformation Execution**: Custom functions must run in sync engine context; preview may differ
19. **Async Validation**: Real-time validation API calls may lag behind user input

    transformationType: 'none' | 'custom' | 'date' | 'text' | 'picklist' | 'formula',
    transformationConfig: {}, // varies by type
    conflictResolution: 'source_wins' | 'destination_wins' | 'most_recent' | 'manual' | 'custom',
    active: boolean,
    lastModified: timestamp,
    createdBy: 'user',
    validationStatus: 'valid' | 'invalid' | 'warning'
  }
]));

// Salesforce schema cache
localStorage.setItem('salesforce_schema_cache', JSON.stringify({
  lastFetched: timestamp,
  ttl: 3600000, // 1 hour
  fields: [
    { name: 'Field__c', type: 'text', label: 'Field Label', required: false }
  ]
}));

// Renzo schema
localStorage.setItem('renzo_schema', JSON.stringify({
  tables: {
    table_name: {
      fields: [
        { name: 'field_name', type: 'varchar', nullable: true }
      ]
    }
  }
}));

// Transformation templates
localStorage.setItem('transformation_templates', JSON.stringify({
  date_formats: ['YYYY-MM-DD', 'MM/DD/YYYY', 'DD-MM-YYYY'],
  text_transforms: ['uppercase', 'lowercase', 'trim', 'regex'],
  formula_functions: ['CONCAT', 'IF', 'DATE', 'ROUND', 'SUBSTRING']
}));

// Mapping validation results
localStorage.setItem('mapping_validation_cache', JSON.stringify({
  'mapping_id': {
    errors: [],
    warnings: [],
    lastChecked: timestamp
  }
}));

### Data Flow Requirements
- **Schema Fetch**: Salesforce API → cache → dropdown population
- **Validation**: Mapping config → validation engine → inline error display
- **Test Transform**: Sample data + mapping → transformation engine → preview display
- **CRUD Operations**: UI changes → localStorage → table re-render
- **Bulk Actions**: Selected rows → batch operation → localStorage update → UI refresh
