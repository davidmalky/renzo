# RESEARCH REPORT: Smart Priority Scoring Addition to Renzo CRM

- **Authentication System**: Login with credentials (admin/renzo2024), stored in localStorage as 'isLoggedIn'
- **Contact Management (CRUD)**:
  - Add/Edit/Delete contacts
  - Contact fields: name, email, company, phone, notes, priority (dropdown)
  - localStorage key: 'contacts' (array of contact objects)
- **Contact Display**:
  - Contact list table with rows (.contact-row)
  - Contact info display (.contact-info, .contact-name, .contact-meta)
  - Priority badge display (.priority-badge with color classes: priority-critical, priority-high, priority-medium, priority-low)
- **Modal System**:
  - Modal overlay/content structure (.modal-overlay, .modal-content)
  - Modal header with title and close button
  - Form groups with labels and inputs (.form-group, .form-label, .form-input)
- **AI Message Generation**:
  - Integration with Anthropic API
  - Message generation for individual contacts
  - "Why this message" info box (trigger-box, trigger-label, trigger-reason classes already exist)
- **Outreach Queue System**:
  - Batch outreach functionality
  - Queue management
- **Drafts System**: Save and manage message drafts
- **Settings Panel**:
  - Trainable instructions section (.trainable-instructions-section)
  - Instructions textarea (.instructions-textarea)
  - API configuration
- **CSV Import**:
  - CSV dropzone (.csv-dropzone)
  - CSV preview table (.csv-preview-table)
  - Column mapping functionality (.column-mapper)
- **Styling System**:
  - CSS custom properties for colors (forest-green theme, priority colors already defined)
  - Button styles (.btn, .btn-primary, .btn-secondary, .btn-danger, .btn-small)
  - Card layout system (.card)
  - Alert system (.alert, .alert-error)

## MISSING_FEATURES:
- **New Contact Fields**: contractExpiry, invoiceAmount, lastContactDate (not in current form)
- **computePriorityScore(contact)** function with scoring algorithm
- **computeOutreachTrigger(contact)** function to determine urgency reason
- **Automatic priority score calculation** (currently manual priority dropdown)
- **Priority-based sorting** of contacts table (default sort by score descending)
- **Dynamic priority badge coloring** based on computed score (80+ red, 50-79 amber, <50 green)
- **Integration of trigger reason** into AI message generation prompt
- **Display of trigger reason** in the message generation UI

## CHANGES_NEEDED:
- **Contact Form HTML**: Add 3 new input fields (contractExpiry date, invoiceAmount number, lastContactDate date)
- **Contact Object Structure**: Extend to include contractExpiry, invoiceAmount, lastContactDate properties
- **Contact Save Function**: Update to capture and store new fields
- **Contact Display**: Modify .contact-row rendering to show computed priority score badge instead of manual priority
- **Contact Sorting Logic**: Implement default sort by computePriorityScore() descending
- **AI Message Generation Function**: 
  - Include computeOutreachTrigger() result in API prompt
  - Display trigger reason in existing .trigger-box element
- **Priority Badge Rendering**: Change from manual priority dropdown value to computed score with 3-tier coloring (red/amber/green)

## REUSE:
- **Existing Priority Badge HTML Structure**: `.priority-badge` with color classes
- **Existing Trigger Box HTML Structure**: `.trigger-box`, `.trigger-label`, `.trigger-reason` (already styled and ready)
- **Form Group Pattern**: Reuse `.form-group`, `.form-label`, `.form-input` for new fields
- **localStorage Pattern**: Continue using `localStorage.getItem('contacts')` and `localStorage.setItem('contacts', JSON.stringify(contacts))`
- **Contact Object Pattern**: Extend existing contact object structure
- **Modal Form Pattern**: Add fields to existing contact form modal
- **CSS Custom Properties**: Use existing `--priority-critical`, `--priority-high`, `--priority-medium`, `--priority-low` for badge coloring
- **Date/Number Input Styling**: Reuse existing `.form-input` class styling
- **Array Sorting Pattern**: Use JavaScript `.sort()` on contacts array before rendering
- **AI Prompt Construction**: Extend existing prompt building logic to include trigger reason

## RISKS:
- **Breaking Existing Priority System**: The manual priority dropdown must be removed/replaced carefully to avoid breaking contact edit functionality
- **localStorage Data Migration**: Existing contacts don't have new fields (contractExpiry, invoiceAmount, lastContactDate) - must handle undefined/null values gracefully
- **Sort Performance**: Recomputing priority scores on every render could be inefficient with large contact lists - compute once and cache
- **Date Calculation Edge Cases**: 
  - Handle missing dates (null/undefined)
  - Handle invalid date formats
  - Timezone considerations for date comparisons
- **Score Display Consistency**: Ensure computed scores override any old manual priority values
- **AI Prompt Length**: Adding trigger reason to prompt must not exceed API token limits
- **Form Validation**: New fields should have appropriate validation (optional vs required, date format, number range)
- **Backward Compatibility**: Old contacts without new fields should still display and function correctly

**localStorage Keys:**
- `'isLoggedIn'`: Boolean string for authentication state
- `'contacts'`: JSON string array of contact objects

**Current Contact Object Structure (inferred):**
```javascript
{

  email: string,
  company: string,
  phone: string,

```

**Required Extended Contact Object Structure:**
```javascript
{
  id: string/number,
  name: string,
  email: string,
  company: string,
  phone: string,
  notes: string,

  contractExpiry: string, // ISO date string "YYYY-MM-DD"

  lastContactDate: string // ISO date string "YYYY-MM-DD"
}
```
