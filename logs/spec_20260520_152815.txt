## OVERVIEW

## FUNCTIONS

**executeBatchOutreach(query):**
1. Parse query string for keywords: "contract"/"expiry"→contractExpiry filter, "invoice"→invoiceAmount filter, "contacted"/"contact"→lastContactDate filter
2. Retrieve contacts array from localStorage key 'renzo_contacts'
3. Filter contacts: if query includes "contract"/"expiry" check contractExpiry exists and within 60 days, if "invoice" check invoiceAmount > 5000, if "contacted" check lastContactDate older than 30 days or null
4. If no matches, show alert-warning "No contacts match your query"
5. Show batchProgress div, initialize progress bar at 0%
6. For each matched contact: call generateAiMessage(contact, loadRules()), add result to queue localStorage key 'renzo_queue', update progress bar (current/total * 100), update batchProgressText "Processing contact X of Y"
7. After completion: render results in batchResults using renderQueueItem() for each, show alert-success "Generated N messages"
8. Hide batchProgress after 1 second delay

**addOutreachRule():**
1. Get value from newRuleInput textarea, trim whitespace
2. If empty, show alert-warning "Please enter a rule" and return
3. Retrieve existing rules from localStorage key 'renzo_rules' (parse JSON array or default [])
4. Create rule object: {id: Date.now(), text: trimmedValue}
5. Push to rules array, save to localStorage as JSON string
6. Clear newRuleInput textarea
7. Call renderRules()
8. Show alert-success "Rule added"

**deleteOutreachRule(ruleId):**
1. Retrieve rules from localStorage key 'renzo_rules'
2. Filter out rule with matching id
3. Save updated array to localStorage
4. Call renderRules()
5. Show alert-success "Rule deleted"

**loadRules():**
1. Retrieve from localStorage key 'renzo_rules'
2. Parse JSON, return array or empty array if null/error
3. Map array to text strings
4. Join with ". " separator
5. Return formatted string: "Additional instructions: [joined rules]." or empty string if no rules

**renderRules():**
1. Call loadRules() to get rules array
2. Clear rulesList innerHTML
3. If rules empty: insert empty-state div with message "No custom rules yet"
4. For each rule: create div with class "rule-item", insert rule text in span, create delete button with onclick="deleteOutreachRule(rule.id)", append to rulesList

**Modify existing generateAiMessage(contact, additionalInstructions=""):**
1. In AI prompt construction, append additionalInstructions parameter to system prompt
2. Format: existing prompt + "\n\n" + additionalInstructions (if not empty)
3. No other changes to function

**Event Listeners (add to existing init/DOMContentLoaded):**
- generateBatchBtn click → executeBatchOutreach(batchPromptInput.value)
- addRuleBtn click → addOutreachRule()
- Sidebar button[data-view="batch"] click → existing view switcher handles

## DATA

- JSON array of rule objects
- Format: [{id: timestamp_number, text: "rule_string"}, ...]

**localStorage 'renzo_contacts' (existing):**
- Access fields: contactExpiry (ISO date string), invoiceAmount (number), lastContactDate (ISO date string or null)

**localStorage 'renzo_queue' (existing):**
- Append new queue items from batch generation

## ERRORS

**Batch Outreach Errors:**
- No query entered: alert-warning "Please enter a search query"
- No matches found: alert-warning "No contacts match your query. Try different keywords."
- AI generation fails for contact: catch error, log to console, continue to next contact, note in batchProgressText "Skipped 1 contact due to error"
- localStorage quota exceeded: alert-error "Storage limit reached. Please clear old queue items."

**Rules Errors:**
- Empty rule submission: alert-warning "Please enter a rule"
- localStorage read failure: console.error, return empty array, continue
- localStorage write failure: alert-error "Could not save rule. Storage may be full."
- Invalid JSON parse: console.error, treat as empty array, reinitialize

**General:**
- View not found (batch): verify div id matches data-view attribute
- Function undefined: verify all functions added to global scope or app object
- Contact data missing fields: use null coalescing, skip filter criteria if field undefined
