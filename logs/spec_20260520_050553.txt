# TECHNICAL SPECIFICATION: SALESFORCE CONNECTOR

## OVERVIEW

Build a complete Salesforce integration system that establishes Renzo's external CRM connectivity architecture. Implement OAuth 2.0 authentication, secure token storage with encryption, one-way contact/account synchronization with field mapping, conflict resolution strategies, and comprehensive sync logging. This connector serves as the template for all future external system integrations (Gmail, HubSpot, etc.) and transforms Renzo into a true "plug-and-play outreach intelligence layer."

## VIEWS

- **settings-view (enhanced)**: Add new "Connected Systems" section above existing Profile section with cards for each integration type. Salesforce card shows connection status (disconnected/connected/syncing/error), "Connect to Salesforce" or "Disconnect" button, last sync timestamp, contact count, and "Configure" button that opens field mapping modal.

- **salesforce-config-modal**: Full-screen modal for Salesforce configuration. Three tabs: "Connection" (OAuth status, authorize/disconnect buttons, connection health indicator), "Field Mapping" (two-column table showing Salesforce fields → Renzo fields with dropdowns for custom mapping), "Sync Settings" (conflict resolution strategy per field, sync frequency options, sync filters like "only sync contacts modified in last X days").

- **salesforce-sync-modal**: Modal showing real-time sync progress with animated progress bar, "Fetching from Salesforce..." status text, counts (X of Y contacts processed), current operation description ("Mapping fields...", "Resolving conflicts...", "Saving to database..."), and detailed log output scrolling in monospace text area. Success/error summary at completion with "View Sync Log" button.

- **salesforce-log-view**: New full view accessible from sidebar (added under Settings). Header with "Salesforce Sync History" title and "Sync Now" button. Table displaying sync operations: timestamp, status (success/partial/failed), records synced, records skipped, duration, error count. Click row to expand inline detail showing: full error messages, list of affected contact emails, conflict resolutions applied, API calls made. Filter controls for date range and status type.

- **salesforce-oauth-popup**: Small centered window (600x700px) that opens during OAuth flow. Displays Salesforce login page via iframe or redirects to Salesforce authorization URL. After user authorizes, captures OAuth callback with authorization code, exchanges for tokens, displays "Authorization successful! Closing window..." message for 2 seconds, then auto-closes and posts message back to parent window.

## FUNCTIONS

- **initSalesforceIntegration()**: Called on app startup. Checks localStorage for encrypted Salesforce tokens. If found, decrypts and validates by making test API call to Salesforce `/services/data/vXX.0/` endpoint. If valid, updates UI to show connected state. If invalid/expired, attempts refresh token flow. If refresh fails, clears stored tokens and shows disconnected state. Registers event listener for OAuth callback messages.

- **connectToSalesforce()**: Triggered by "Connect to Salesforce" button. Generates random state parameter (UUID), stores in sessionStorage for CSRF protection. Constructs Salesforce OAuth URL: `https://login.salesforce.com/services/oauth2/authorize?response_type=code&client_id={CLIENT_ID}&redirect_uri={REDIRECT_URI}&state={STATE}&scope=api refresh_token`. Opens popup window centered on screen. Returns promise that resolves when OAuth completes or rejects on error/timeout (5 minute timeout).

- **handleSalesforceOAuthCallback(code, state)**: Receives authorization code from OAuth popup. Validates state parameter matches stored value. Makes POST to Salesforce token endpoint: `https://login.salesforce.com/services/oauth2/token` with grant_type=authorization_code, code, client_id, client_secret, redirect_uri. Receives access_token, refresh_token, instance_url, issued_at. Encrypts tokens using encryptSalesforceTokens(). Stores encrypted data in localStorage key `salesforce_auth`. Updates UI to connected state. Triggers initial sync automatically. Closes OAuth popup.

- **encryptSalesforceTokens(tokenData)**: Uses Web Crypto API (SubtleCrypto) to encrypt sensitive token data. Generates encryption key from user's email + fixed salt using PBKDF2 (100,000 iterations). Encrypts JSON.stringify(tokenData) using AES-GCM with random IV. Returns base64-encoded object: `{iv: base64_iv, data: base64_encrypted_data, salt: base64_salt}`. If Web Crypto not available (older browsers), falls back to storing warning flag and using base64 encoding (not secure but functional).

- **decryptSalesforceTokens(encryptedData)**: Reverses encryption process. Parses base64 object, derives key using same PBKDF2 process, decrypts using AES-GCM with stored IV. Returns parsed tokenData object with access_token, refresh_token, instance_url, issued_at. Catches decryption errors and returns null (triggers re-auth flow). Handles fallback base64 decoding if encryption wasn't available.

- **refreshSalesforceToken()**: Called when access token expires (detected by 401 response). Makes POST to `https://login.salesforce.com/services/oauth2/token` with grant_type=refresh_token, refresh_token, client_id, client_secret. Receives new access_token and issued_at (refresh_token remains same). Updates encrypted storage with new tokens. Returns promise resolving to new access_token or rejecting if refresh fails (triggers full re-auth). Implements retry logic (3 attempts with exponential backoff).

- **disconnectSalesforce()**: Triggered by "Disconnect" button. Shows confirmation modal: "Disconnect from Salesforce? Your synced contacts will remain in Renzo, but future updates won't sync." If confirmed, makes POST to Salesforce revoke endpoint: `https://login.salesforce.com/services/oauth2/revoke?token={access_token}`. Removes localStorage key `salesforce_auth`. Removes localStorage key `salesforce_field_mappings`. Keeps sync logs and synced contacts (only removes foreign key references). Updates UI to disconnected state. Shows success toast.

- **syncFromSalesforce()**: Main sync orchestration function. Shows salesforce-sync-modal. Calls fetchSalesforceAccounts() and fetchSalesforceContacts() in parallel. Waits for both to complete. Calls mergeSalesforceData() with fetched results. Updates sync status in localStorage. Hides modal and shows completion toast with summary: "Synced 47 contacts, 12 updated, 3 skipped". Catches errors and displays in modal with "Retry" and "Close" buttons. Logs full operation to sync history.

- **fetchSalesforceAccounts()**: Makes authenticated GET to `/services/data/v58.0/query?q=SELECT Id, Name, AnnualRevenue, LastActivityDate FROM Account WHERE LastModifiedDate > {lastSyncDate} ORDER BY LastModifiedDate ASC LIMIT 2000`. Uses salesforceApiRequest() helper. Parses response JSON, extracts records array. If more than 2000 results, follows nextRecordsUrl pagination links until all fetched. Returns array of Account objects. Updates modal progress: "Fetched X accounts...". Handles SOQL query errors (invalid fields, permission issues) and logs to console and sync log.

- **fetchSalesforceContacts()**: Makes authenticated GET to `/services/data/v58.0/query?q=SELECT Id, Email, FirstName, LastName, Phone, AccountId, Title, Account.Name FROM Contact WHERE LastModifiedDate > {lastSyncDate} AND Email != null ORDER BY LastModifiedDate ASC LIMIT 2000`. Follows pagination like fetchSalesforceAccounts(). Returns array of Contact objects with nested Account data. Updates modal progress: "Fetched X contacts...". Handles contacts without emails (skips them, increments skip counter).

- **mergeSalesforceData(accounts, contacts)**: Core data merging logic. Iterates through contacts array. For each contact: (1) Maps Salesforce fields to Renzo fields using getFieldMapping(). (2) Looks up existing Renzo contact by email using findContactByEmail(). (3) If not found, creates new contact with createContactFromSalesforce(). (4) If found, applies conflict resolution using resolveFieldConflicts(). (5) Stores Salesforce ID in contact.integrations.salesforce = {id, lastSyncedAt, accountId}. (6) Calls updateContact() or addContact() accordingly. Updates modal progress after each batch of 50. Returns summary object: {synced: count, created: count, updated: count, skipped: count, errors: [array]}.

- **getFieldMapping()**: Retrieves field mapping configuration from localStorage key `salesforce_field_mappings`. Returns object mapping Salesforce field paths to Renzo field names: `{"Account.Name": "company", "Email": "email", "Phone": "phone", "Account.AnnualRevenue": "revenue", "Contract.EndDate": "contractExpiry", "Account.LastActivityDate": "lastContactDate"}`. If no custom mapping exists, returns default mapping (hardcoded in function). Used by mergeSalesforceData to know which fields to extract.

- **applyFieldMapping(salesforceContact, salesforceAccount, mapping)**: Takes raw Salesforce Contact and Account objects plus mapping configuration. Returns normalized Renzo contact object. Iterates mapping entries: for each Salesforce field path (e.g., "Account.Name"), uses getNestedProperty() to extract value from source objects. Assigns to Renzo field name. Handles data type conversions: (1) Revenue: converts string to number, strips currency symbols. (2) Dates: converts Salesforce ISO strings to Date objects, then to ISO string for storage. (3) Phone: formats to consistent pattern. (4) Name: combines FirstName + LastName if separate. Returns complete contact object ready for database.

- **findContactByEmail(email)**: Searches localStorage contacts array for existing contact with matching email (case-insensitive). Returns contact object if found, null otherwise. Used to determine if sync should update existing or create new. Handles multiple matches (should never happen but logs warning and returns first match).

- **createContactFromSalesforce(mappedData)**: Creates new Renzo contact from Salesforce data. Generates new UUID for id. Sets default values for Renzo-specific fields not in Salesforce (priority="medium", relationship="prospect", notes=""). Adds integrations.salesforce metadata: {id: salesforceId, accountId: salesforceAccountId, lastSyncedAt: new Date().toISOString(), source: "salesforce_sync"}. Calls addContact() and returns result. Increments "created" counter in sync summary.

- **resolveFieldConflicts(existingContact, newData, strategy)**: Compares existing Renzo contact with new Salesforce data. For each field, applies resolution strategy from localStorage key `salesforce_conflict_resolution` (default: "salesforce_wins"). Strategies: (1) "salesforce_wins": always take Salesforce value. (2) "renzo_wins": keep existing Renzo value, ignore Salesforce. (3) "newest_wins": compare lastModified timestamps, take newer. (4) "manual_review": add to conflicts array, skip auto-merge. Returns merged contact object and conflicts array for manual review. Updates "updated" or "skipped" counter accordingly.

- **updateContactWithSalesforceData(contactId, mergedData)**: Calls existing updateContact() function with merged data. Preserves Renzo-specific fields that don't exist in Salesforce (notes, priority, custom tags). Updates integrations.salesforce.lastSyncedAt timestamp. Returns success boolean. Catches validation errors (e.g., invalid email format after merge) and logs to sync errors array.

- **saveSyncLog(logEntry)**: Appends new sync operation to localStorage key `salesforce_sync_logs` (array). Log entry structure: {id: UUID, timestamp: ISO string, status: "success"|"partial"|"failed", duration: milliseconds, summary: {synced, created, updated, skipped}, errors: [{contact_email, error_message, salesforce_id}], apiCalls: count}. Limits array to last 100 sync operations (removes oldest if exceeded). Triggers UI update in salesforce-log-view if currently visible.

- **getSyncLogs(filters)**: Retrieves sync logs from localStorage, applies filters (date range, status type), sorts by timestamp descending. Returns filtered array. Used by salesforce-log-view to populate table. Handles empty array case (shows "No sync history yet" message).

- **getLastSyncTime()**: Reads most recent sync log entry, returns timestamp. If no logs exist, returns null. Used to display "Last synced: 2 hours ago" in UI and to construct SOQL query filters (only fetch records modified since last sync). Formats timestamp using formatRelativeTime() helper.

- **salesforceApiRequest(endpoint, options)**: Wrapper for all Salesforce API calls. Handles authentication (adds Bearer token to headers), instance URL resolution (uses stored instance_url from token data), retry logic on 401 (calls refreshSalesforceToken() and retries), network error handling, timeout (30 seconds), response parsing. Returns promise resolving to parsed JSON or rejecting with detailed error. Logs all API calls for debugging. Increments apiCalls counter in current sync operation.

- **showSalesforceConfigModal()**: Opens salesforce-config-modal. Loads current field mappings from localStorage and populates Field Mapping tab table. Loads conflict resolution strategies and populates dropdowns. Initializes tab navigation (defaults to Connection tab). Binds save button to saveFieldMappings() and saveSyncSettings(). Binds cancel button to hideModal(). If not connected, disables Field Mapping and Sync Settings tabs (shows "Connect to Salesforce first" overlay).

- **renderFieldMappingTable()**: Generates HTML for field mapping configuration table. Left column: Salesforce fields (dropdown with all available fields from Salesforce schema). Right column: Renzo fields (dropdown with all contact fields). Each row has delete button. "Add Mapping" button at bottom adds new row. Pre-populates with current mappings from localStorage. Highlights required mappings (email must be mapped). Validates that Renzo email field isn't mapped to multiple Salesforce fields.

- **saveFieldMappings()**: Reads values from field mapping table rows. Constructs mapping object. Validates: (1) Email mapping exists. (2) No duplicate Renzo field assignments. (3) All Salesforce field paths are valid (checks against schema). Saves to localStorage key `salesforce_field_mappings`. Shows success toast. If validation fails, highlights errors in red and shows error toast with details.

- **renderConflictResolutionSettings()**: Generates HTML for per-field conflict resolution configuration. Lists all mapped Renzo fields. For each field, dropdown with options: "Salesforce wins", "Renzo wins", "Newest wins", "Manual review". Loads current strategies from localStorage key `salesforce_conflict_resolution` (defaults to "Salesforce wins" for all). Shows explanation tooltip for each strategy.

- **saveSyncSettings()**: Reads conflict resolution dropdowns and other sync settings (sync frequency, filters). Validates settings. Saves to localStorage key `salesforce_sync_settings`. Updates sync behavior immediately (no restart required). Shows success toast. If scheduled sync enabled, registers sync interval using setInterval().

- **manualSyncNow()**: Triggered by "Sync Now" button in settings card or log view header. Checks if currently syncing (prevents concurrent syncs). Calls syncFromSalesforce(). Disables button and shows spinner during sync. Re-enables and updates last sync time on completion. Handles errors by showing error modal with details and "Retry" option.

- **renderConnectedSystemsSection()**: Generates HTML for new "Connected Systems" section in settings-view. Creates card for Salesforce (currently only integration). Card shows: logo, connection status badge (green dot + "Connected" or red dot + "Disconnected"), last sync time, contact count from Salesforce, action buttons ("Configure", "Sync Now", "Disconnect"). Placeholder cards for future integrations (Gmail, HubSpot) with "Coming Soon" overlay. Uses CSS Grid for responsive layout (1 column mobile, 2 columns tablet, 3 columns desktop).

- **updateSalesforceConnectionStatus(status)**: Updates UI elements showing Salesforce connection state. Status values: "disconnected", "connected", "syncing", "error". Changes badge color/text, enables/disables buttons, shows/hides sync progress indicators. Called after connection changes, during sync, and on errors. Updates data attribute `data-sf-status` on connection card for CSS styling.

- **formatSalesforceError(error)**: Formats Salesforce API errors into user-friendly messages. Handles common error codes: (1) INVALID_SESSION_ID → "Session expired. Reconnecting...". (2) REQUEST_LIMIT_EXCEEDED → "Salesforce API limit reached. Try again in X hours." (3) INVALID_FIELD → "Field 'X' not found. Check field mappings.". (4) INSUFFICIENT_ACCESS → "Missing permissions for 'X'. Contact Salesforce admin.". Returns formatted string for display in modals/toasts.

- **getSalesforceSchema()**: Fetches Salesforce object metadata for dynamic field mapping UI. Makes GET to `/services/data/v58.0/sobjects/Contact/describe` and `/services/data/v58.0/sobjects/Account/describe`. Parses response to extract field names, labels, types. Caches in sessionStorage for performance (valid for session). Returns object: {Contact: {fields: []}, Account: {fields: []}}. Used to populate field dropdowns in mapping configuration. Updates cache on reconnection (schema may change).

- **validateSalesforceConnection()**: Makes test API call to `/services/data/v58.0/limits` endpoint. Returns promise resolving to true if successful, false if error. Called periodically (every 5 minutes) when connected to detect auth issues proactively. Updates connection health indicator (green/yellow/red dot with tooltip showing last check time). Triggers re-auth if validation fails repeatedly (3 consecutive failures).

- **scheduledSyncJob()**: Background function that runs on configured interval (e.g., every hour). Checks if scheduled sync enabled in settings. Checks if currently syncing (skips if yes). Checks last sync time and interval setting to determine if sync due. If all conditions met, calls syncFromSalesforce() silently (no modal, just toast on completion). Logs to sync history as scheduled_sync type. Handles errors gracefully (doesn't block subsequent scheduled syncs).

- **exportSyncLog(logId)**: Exports specific sync log entry as JSON file. Retrieves log from localStorage, formats as pretty-printed JSON. Triggers browser download using Blob and URL.createObjectURL(). Filename: `salesforce-sync-{timestamp}.json`. Used for debugging and audit purposes. Includes full error details and affected contact list.

- **clearSyncHistory()**: Triggered by "Clear History" button in log view (with confirmation). Removes all entries from localStorage key `salesforce_sync_logs`. Shows success toast. Refreshes log view to show empty state. Does not affect actual contact data (only clears operation logs).

- **getSyncStatistics()**: Calculates aggregate statistics from sync logs. Returns object: {totalSyncs: count, totalContactsSynced: count, successRate: percentage, averageDuration: milliseconds, lastError: string, mostRecentSync: timestamp}. Used in dashboard and connection card to show integration health. Caches result for 1 minute to avoid recomputing on every render.

- **handleSyncConflicts(conflicts)**: Opens modal showing conflicts requiring manual review. Lists each contact with conflicting fields side-by-side: Renzo value | Salesforce value. User selects which to keep for each field. "Apply" button saves selections and completes sync for those contacts. "Skip All" button leaves contacts unchanged (logs as skipped). Stores user selections to learn preferences (suggest auto-resolution strategy based on past choices).

- **migrateExistingContacts()**: One-time function called after first successful Salesforce connection. Scans all existing Renzo contacts, searches Salesforce for matching emails. If match found, adds integrations.salesforce metadata to link records. Shows progress modal during migration. Returns summary: X contacts linked, Y not found in Salesforce. Prevents duplicate syncing of contacts that existed before integration was set up.

- **testSalesforceConnection()**: Debug utility function accessible from browser console. Makes series of test API calls (query contacts, query accounts, describe objects, check limits). Logs detailed results to console. Returns health report object. Used for troubleshooting integration issues. Button in config modal triggers this with results displayed in popup.

## DATA

- **salesforce_auth** (localStorage): Encrypted object containing Salesforce OAuth tokens and metadata. Structure after decryption: `{access_token: string (JWT), refresh_token: string, instance_url: string (e.g., "https://na1.salesforce.com"), issued_at: ISO timestamp, expires_in: seconds (typically 7200), scope: string, token_type: "Bearer", user_id: Salesforce user ID}`. Never store unencrypted. Cleared on disconnect or auth failure.

- **salesforce_field_mappings** (localStorage): Object defining custom field mappings. Keys are Salesforce field paths (dot notation for nested fields like "Account.Name"), values are Renzo field names. Example: `{"Email": "email", "Phone": "phone", "Account.Name": "company", "Account.AnnualRevenue": "revenue", "Title": "title", "Account.LastActivityDate": "lastContactDate"}`. Defaults loaded if not set. Modified via config modal.

- **salesforce_conflict_resolution** (localStorage): Object defining conflict resolution strategies per field. Keys are Renzo field names, values are strategy identifiers. Example: `{"email": "salesforce_wins", "phone": "newest_wins", "company": "renzo_wins", "notes": "renzo_wins"}`. Default: "salesforce_wins" for all mapped fields except notes (always "renzo_wins"). Modified via config modal.

- **salesforce_sync_settings** (localStorage): Object containing sync behavior configuration. Structure: `{scheduledSyncEnabled: boolean, syncInterval: number (minutes), syncFilters: {onlyModifiedSince: boolean, includeDeletedContacts: boolean}, conflictNotifications: boolean, autoResolutionLearning: boolean}`. Defaults: scheduled disabled, 60 minute interval, modified since enabled, deleted excluded, notifications enabled, learning enabled.

- **salesforce_sync_logs** (localStorage): Array of sync operation log entries (max 100, FIFO). Each entry: `{id: UUID, timestamp: ISO string, type: "manual"|"scheduled"|"initial", status: "success"|"partial"|"failed", duration: milliseconds, summary: {fetched: number, created: number, updated: number, skipped: number, errors: number}, errors: [{contactEmail: string, errorMessage: string, errorCode: string, salesforceId: string}], apiCalls: number, conflictsResolved: number, conflictsPending: number}`. Used for history view and statistics.

- **contacts[].integrations.salesforce** (localStorage, nested in contact objects): Metadata linking Renzo contact to Salesforce records. Structure: `{id: Salesforce Contact ID (18 char), accountId: Salesforce Account ID (18 char), lastSyncedAt: ISO timestamp, lastModifiedInSalesforce: ISO timestamp, source: "salesforce_sync"|"manual_link", syncStatus: "synced"|"conflict"|"error", errorMessage: string (if error)}`. Added during sync, used for matching and future two-way sync.

- **salesforce_schema_cache** (sessionStorage): Cached Salesforce object metadata. Structure: `{Contact: {label: "Contact", fields: [{name: "Email", label: "Email", type: "email", updateable: true}, ...]}, Account: {label: "Account", fields: [...]}, fetchedAt: ISO timestamp}`. Expires on browser close. Used to populate field dropdowns without repeated API calls. Refreshed on reconnection.

- **salesforce_oauth_state** (sessionStorage): Temporary storage for OAuth CSRF state parameter. Structure: `{state: UUID, timestamp: ISO timestamp, expiresAt: ISO timestamp (5 min from creation)}`. Created when OAuth flow starts, validated on callback, then deleted. Prevents OAuth hijacking attacks.

- **salesforce_last_sync** (localStorage): Simple timestamp of most recent successful sync completion. Used for quick "last synced" display without loading full logs array. Updated at end of syncFromSalesforce(). Format: ISO string. Displayed in UI as relative time ("2 hours ago").
