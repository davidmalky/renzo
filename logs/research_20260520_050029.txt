## RISKS:

### Security Vulnerabilities
- **CRITICAL**: Storing OAuth tokens in localStorage without encryption exposes sensitive credentials
  - Tokens accessible via XSS attacks
  - Tokens visible in browser DevTools
  - No token expiration enforcement
  - Recommendation: Implement proper encryption before storing tokens

### localStorage Limitations
- **HIGH**: localStorage has ~5-10MB limit per origin
  - Salesforce data + contacts + sync logs could exceed limit
  - No quota management currently exists
  - Risk: Data loss or sync failure when quota exceeded
  - Recommendation: Implement data archiving or quota monitoring

### OAuth Flow Complexity
- **MEDIUM**: Redirect-based OAuth in single-page app challenges
  - State management lost during redirect
  - Need to persist OAuth state in localStorage
  - Popup blockers may prevent OAuth popup window
  - Recommendation: Use authorization code flow with PKCE, handle state preservation

### CORS & API Restrictions
- **HIGH**: Salesforce API calls from browser will hit CORS restrictions
  - Salesforce doesn't allow direct browser-to-API calls from arbitrary origins
  - Need proxy server or Salesforce Connected App with proper CORS config
  - Current codebase has no backend/proxy
  - Recommendation: Document CORS workaround requirements (proxy or Salesforce CORS whitelist)

### Data Conflict Complexity
- **MEDIUM**: Merge conflicts can create data inconsistencies
  - Timestamp comparison unreliable if clocks are skewed
  - Partial sync failures leave data in inconsistent state
  - "Manual review" strategy requires complex UI state management
  - Recommendation: Implement transaction-like rollback for failed syncs

### Rate Limiting
- **MEDIUM**: Salesforce API has strict rate limits
  - No rate limit tracking in current code
  - Batch sync of large contact lists could trigger limits
  - No exponential backoff retry logic
  - Recommendation: Implement rate limit headers tracking and request throttling

### Token Refresh Timing
- **MEDIUM**: Access tokens expire (typically 2 hours for Salesforce)
  - No token expiration detection
  - No automatic refresh token flow
  - Sync could fail mid-operation due to token expiry
  - Recommendation: Implement preemptive token refresh before API calls

### Field Mapping Validation
- **LOW**: Invalid field mappings could cause sync errors
  - No validation that Salesforce fields exist
  - No type compatibility checking (e.g., mapping date to string)
  - Required fields might not be mapped
  - Recommendation: Validate mappings against Salesforce schema metadata

### Concurrent Modification
- **LOW**: Multiple browser tabs could cause race conditions
  - Current localStorage access is not locked
  - Simultaneous syncs could corrupt data
  - Recommendation: Implement tab coordination via localStorage events or leader election

### Backward Compatibility
- **LOW**: Adding fields to contact schema affects existing contacts
  - Existing contacts won't have new Salesforce fields
  - Need migration logic to add default values
  - Recommendation: Implement schema versioning and migration on load
