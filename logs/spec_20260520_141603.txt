# TECHNICAL SPECIFICATION: Smart Priority Scoring for Renzo CRM

## OVERVIEW
Add intelligent priority scoring to existing Renzo CRM contacts without disrupting current functionality. Extend contact model with three date/financial fields, implement scoring algorithm (0-100 based on contact recency, contract urgency, invoice amount), auto-sort contacts by computed score, and integrate priority triggers into AI message generation context.

## FUNCTIONS

- **saveContact(contactData) - MODIFY**:
  1. Accept existing contact object structure
  2. Add three new fields: contractExpiry (string/null), invoiceAmount (number, default 0), lastContactDate (string/null)
  3. Before saving to localStorage, compute and attach priorityScore using computePriorityScore(contactData)
  4. Proceed with existing save logic (localStorage 'contacts' array update)
  5. Return saved contact object with computed score

- **computePriorityScore(contact) - NEW**:
  1. Initialize score = 0
  2. Calculate lastContactDate score:
     - If lastContactDate exists: daysSince = (today - lastContactDate) / 86400000
     - score += Math.min(daysSince / 90, 1) * 40
  3. Calculate contract expiry score:
     - If contractExpiry exists: daysUntil = (contractExpiry - today) / 86400000
     - If daysUntil between 0-90: score += (1 - daysUntil / 90) * 30
     - If daysUntil < 0 (expired): score += 30
  4. Calculate invoice score:
     - If invoiceAmount > 0: score += Math.min(invoiceAmount / 10000, 1) * 30
  5. Return Math.round(score)

- **computeOutreachTrigger(contact) - NEW**:
  1. Initialize mostUrgent = null, urgencyValue = 0
  2. Check contract expiry (highest priority):
     - If contractExpiry exists: calculate daysUntil
     - If daysUntil < 0: return `Contract expired ${Math.abs(daysUntil)} days ago`
     - If daysUntil <= 90: set urgencyValue = 90 - daysUntil, mostUrgent = `Contract expires in ${daysUntil} days`
  3. Check invoice (second priority):
     - If invoiceAmount >= 1000 and urgencyValue < 50: mostUrgent = `Invoice $${invoiceAmount.toLocaleString()} outstanding`
  4. Check last contact (third priority):
     - If lastContactDate exists and mostUrgent still null: daysSince = days calculation
     - If daysSince > 30: mostUrgent = `Not contacted in ${daysSince} days`
  5. Return mostUrgent || 'Routine follow-up'

- **renderContactsList() - MODIFY**:
  1. Load contacts from localStorage
  2. For each contact: compute priorityScore if not present, attach to object
  3. Sort array: contacts.sort((a, b) => b.priorityScore - a.priorityScore)
  4. Render each row with existing structure
  5. Replace priority badge rendering with score badge:
     - Create span.priority-score-badge
     - Set textContent to contact.priorityScore
     - Set data-score-level: score >= 80 ? 'high' : score >= 50 ? 'medium' : 'low'
  6. Maintain all existing click handlers and row structure

- **showContactForm(contact = null) - MODIFY**:
  1. Execute existing modal open logic
  2. If editing (contact exists): populate new fields:
     - Set contractExpiry input value to contact.contractExpiry || ''
     - Set invoiceAmount input value to contact.invoiceAmount || 0
     - Set lastContactDate input value to contact.lastContactDate || ''
  3. If creating new: ensure new fields are empty
  4. Maintain all existing form behaviors

- **generateAIMessage(contact) - MODIFY**:
  1. Execute existing API key validation
  2. Call computeOutreachTrigger(contact) to get trigger string
  3. Modify prompt construction: append trigger context:
     - "Context: This outreach is triggered by: [trigger]. Consider this in your message tone and content."
  4. Proceed with existing Anthropic API call
  5. After message generation: update .trigger-reason element with trigger string
  6. Maintain existing error handling and UI updates

## ERRORS

- **Invalid Date Inputs**:
  - Handle null/empty date fields gracefully in computePriorityScore (skip that scoring component)
  - No error display needed; treat as missing data (score = 0 for that component)

- **Invalid Invoice Amount**:
  - If invoiceAmount < 0 or NaN: treat as 0 in computePriorityScore
  - No user-facing error; sanitize on save

- **Missing priorityScore on Existing Contacts**:
  - On renderContactsList(): check if contact.priorityScore exists
  - If missing: compute on-the-fly and update contact object in array
  - Re-save contacts array to localStorage with computed scores

- **Sorting Empty Array**:
  - If no contacts exist: renderContactsList() handles gracefully (existing code should already handle)
  - Ensure sort() doesn't throw on empty array (it won't, but verify in testing)

- **API Context Too Long**:
  - Trigger string max length: cap computeOutreachTrigger() output at 100 chars
  - If trigger string exceeds: truncate with "..." suffix
  - Prevents token overflow in Anthropic prompt
