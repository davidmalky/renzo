# TECHNICAL SPECIFICATION: CONTACT SYNC DASHBOARD & ACTIVITY LOG

## OVERVIEW

This system creates a comprehensive sync monitoring dashboard within the Integrations settings, providing real-time visibility into Salesforce-Renzo contact synchronization operations. The SyncActivityView displays sync health metrics, live progress tracking, detailed activity logs with field-level change history, error analysis, and manual sync controls. The dashboard auto-refreshes during active syncs, supports historical data filtering, provides actionable error insights, and enables CSV export of sync logs for auditing and troubleshooting purposes.

## VIEWS

- **SyncActivityView**: Main dashboard view displaying sync status overview card (health indicator, last sync time, manual trigger button), real-time progress indicator with operation details, activity log table with expandable rows showing field changes, filter controls (date range, status, record type), error summary section with resolution suggestions, sync statistics cards (30-day metrics, error rates), and CSV export functionality. Layout uses grid system with sidebar navigation integration.

- **SyncStatusCard**: Top-level status overview component showing sync health indicator (green/yellow/red dot based on error rate thresholds), last successful sync timestamp with relative time formatting, total contacts synced counter, manual "Sync Now" button with loading state, and sync frequency settings link.

- **SyncProgressIndicator**: Real-time progress tracking component displaying horizontal progress bar (0-100%), current operation description text ("Syncing contacts...", "Checking for updates...", "Updating contact: John Doe"), records processed counter ("247/500 contacts"), estimated time remaining, and animated spinner during active operations. Conditionally rendered only when sync is in progress.

- **ActivityLogTable**: Paginated table displaying sync activity records with columns: timestamp (sortable), operation type icon/badge (initial sync/update/error/manual), Salesforce record ID (clickable link), Renzo contact name (clickable link), sync direction indicator (→ Salesforce, ← Renzo, ↔ bidirectional), status badge (success/failed/conflict/skipped), and expand/collapse chevron icon. Rows are expandable to show field-level change details.

- **ActivityLogDetailRow**: Expandable row content showing field-by-field comparison with three columns: field name, old value (with null/empty indicators), new value (with null/empty indicators), change type indicator (added/modified/deleted/conflict). Displays sync metadata (duration, retry count, error message if failed), and action buttons (retry sync, view full record, report issue).

- **FilterControlBar**: Horizontal filter bar with date range picker (preset options: today/7 days/30 days/custom), status multi-select dropdown (all/success/failed/conflict/skipped), record type filter (contact/lead/account), operation type filter (initial/update/delete), search input for contact name/Salesforce ID, and "Reset Filters" button.

- **ErrorSummarySection**: Collapsible section displaying error analysis with grouped error types (authentication failures, field mapping errors, validation errors, network timeouts, duplicate records, permission errors). Each error group shows count badge, most recent occurrence timestamp, quick resolution suggestion text, and "View Affected Records" link to filter activity log.

- **SyncStatisticsCards**: Grid of four stat cards showing: (1) Total syncs in last 30 days with trend indicator, (2) Average sync duration in seconds/minutes with performance indicator, (3) Error rate percentage with threshold-based color coding, (4) Last successful sync timestamp with relative time. Each card includes icon, primary metric, and delta/trend information.

- **ExportSyncLogModal**: Modal dialog for CSV export configuration with options: date range selection, columns to include (checkboxes for all available fields), status filter inclusion, record limit input, file format option (CSV/JSON), and "Download Report" button with progress indicator.

- **ManualSyncModal**: Confirmation modal for manual sync trigger with options: sync type (full/incremental), direction (bidirectional/to Salesforce/from Salesforce), conflict resolution strategy (newest wins/manual review/skip conflicts), dry run checkbox (preview changes without applying), and "Start Sync" button with warning text about potential data overwrites.

- **RetryFailedRecordModal**: Modal for retrying individual failed sync records showing original error message, record preview (key fields), retry options (use same settings/modify field mappings), conflict resolution choice if applicable, and "Retry Sync" button with loading state.

- **SyncToastNotification**: Toast notification component appearing top-right for sync events with variants: success (green, checkmark icon, "Sync completed: 247 contacts updated"), error (red, X icon, "Sync failed: Authentication error"), warning (yellow, exclamation icon, "Sync completed with 12 warnings"), info (blue, i icon, "Sync started"). Auto-dismisses after 5 seconds with manual close button.

## FUNCTIONS

- **initializeSyncActivityView()**: Initializes the sync activity dashboard by setting up event listeners, loading initial sync status data via fetchCurrentSyncStatus(), populating activity log table with fetchActivityLog(defaultFilters), rendering statistics cards with fetchSyncStatistics(30days), checking for active sync with checkActiveSyncStatus() and starting auto-refresh if needed, initializing filter controls with default values, setting up modal event handlers, and applying saved user preferences for table columns and filters.

- **fetchCurrentSyncStatus()**: Makes GET request to /api/salesforce/sync/status endpoint to retrieve current sync state including: isSyncing boolean, currentOperation object (type, description, startTime), lastSyncTimestamp, lastSuccessfulSyncTimestamp, totalContactsSynced, healthStatus (healthy/degraded/critical), errorRate percentage, and activeProgress object (current, total, percentage). Updates SyncStatusCard UI and determines if progress indicator should be shown. Handles network errors with retry logic (3 attempts with exponential backoff) and displays error toast on failure.

- **fetchActivityLog(filters, page, pageSize)**: Makes POST request to /api/salesforce/sync/activity endpoint with filter payload containing: dateRange (startDate, endDate), statusFilter array (success/failed/conflict/skipped), recordTypeFilter array (contact/lead/account), operationTypeFilter array (initial/update/delete), searchQuery string, sortColumn string, sortDirection (asc/desc), page integer, pageSize integer. Receives paginated response with items array (each containing: id, timestamp, operationType, salesforceRecordId, salesforceRecordType, renzoContactId, renzoContactName, syncDirection, status, errorMessage, duration, retryCount, fieldChanges array), totalCount, currentPage, totalPages. Updates ActivityLogTable with new data and pagination controls. Caches results for 30 seconds to reduce API calls.

- **fetchSyncStatistics(timeRange)**: Makes GET request to /api/salesforce/sync/statistics?range={timeRange} endpoint to retrieve aggregated metrics including: totalSyncs integer, totalRecordsProcessed integer, successfulSyncs integer, failedSyncs integer, averageSyncDuration float (seconds), errorRate float (percentage), syncFrequency object (byDay array of {date, count}), commonErrors array of {errorType, count, lastOccurrence}, performanceTrend string (improving/stable/degrading). Updates SyncStatisticsCards with formatted values and calculates trend indicators by comparing with previous period. Displays error message in statistics section if API call fails.

- **startManualSync(syncOptions)**: Validates user permissions for manual sync trigger, displays ManualSyncModal for user to configure sync parameters (syncType: full/incremental, direction: bidirectional/toSalesforce/fromRenzo, conflictResolution: newestWins/manualReview/skipConflicts, dryRun: boolean), on confirmation makes POST request to /api/salesforce/sync/trigger endpoint with payload: {syncType, direction, conflictResolution, dryRun, triggeredBy: currentUserId, triggeredAt: timestamp}. Receives syncJobId in response, immediately calls checkActiveSyncStatus() to start monitoring, enables progress indicator, starts auto-refresh polling, displays info toast "Sync started", and disables manual sync button until completion.

- **checkActiveSyncStatus()**: Makes GET request to /api/salesforce/sync/active endpoint to check if sync is currently running. Returns syncJob object if active (containing: jobId, status (running/queued/paused), startTime, currentOperation, progress {current, total, percentage}, estimatedTimeRemaining seconds) or null if no active sync. If active sync found, updates SyncProgressIndicator with real-time data, starts auto-refresh polling with startAutoRefresh(), and enables live progress updates. If no active sync and auto-refresh is running, stops auto-refresh with stopAutoRefresh().

- **startAutoRefresh()**: Initiates polling mechanism using setInterval() with 30-second interval to continuously refresh sync data during active syncs. Each interval calls checkActiveSyncStatus() to update progress, and if sync is still active, calls fetchActivityLog() with current filters to show new activity records, and updates timestamp displays with updateRelativeTimestamps(). Stores interval ID in component state for cleanup. Adds visual indicator (pulsing dot) next to "Last Updated" timestamp to show live refresh is active.

- **stopAutoRefresh()**: Clears polling interval using clearInterval() with stored interval ID, removes live refresh visual indicator, makes final call to fetchActivityLog() to ensure latest data is displayed, updates SyncStatusCard with final sync status, displays completion toast notification (success or error based on final status), re-enables manual sync button, and resets progress indicator visibility to hidden.

- **updateSyncProgress(progressData)**: Updates SyncProgressIndicator component with current sync progress data including: progress percentage (animates progress bar width from current to new value over 0.5s), currentOperation description text (with fade transition between operations), recordsProcessed counter ("247/500 contacts" format), estimatedTimeRemaining (formatted as "About 2 minutes remaining"), and operation type (updates background color pulse animation speed based on operation intensity). Handles progress data validation to ensure percentage is 0-100 range.

- **expandActivityLogRow(rowId)**: Handles expansion of activity log table row to show detailed field changes. On click of chevron icon, toggles row expansion by adding/removing "expanded" class, rotates chevron icon 90 degrees, fetches detailed sync record data if not already loaded via fetchSyncRecordDetails(rowId), renders ActivityLogDetailRow with field-by-field comparison showing oldValue and newValue for each changed field, highlights conflict fields in yellow, displays sync metadata (duration, retry attempts, error messages), and renders action buttons (Retry, View Record, Report Issue). Collapses previously expanded rows to keep UI clean (accordion behavior).

- **fetchSyncRecordDetails(syncRecordId)**: Makes GET request to /api/salesforce/sync/activity/{syncRecordId}/details endpoint to retrieve complete sync record information including: fullSalesforceRecord object, fullRenzoContact object, fieldChanges array of {fieldName, oldValue, newValue, changeType (added/modified/deleted), conflictDetected boolean, conflictResolution string}, syncMetadata object (startTime, endTime, duration, retryCount, retryHistory array, errorDetails object, syncDirection, triggeredBy), and auditLog array. Returns detailed data for rendering in expandable row. Caches response to avoid redundant API calls when row is toggled.

- **applyActivityLogFilters()**: Collects current filter values from FilterControlBar inputs (dateRange from date pickers, statusFilter from multi-select, recordTypeFilter from dropdown, operationTypeFilter from checkboxes, searchQuery from text input), validates date range (ensures endDate >= startDate), constructs filter object, stores filters in component state and localStorage for persistence, resets pagination to page 1, calls fetchActivityLog(filters, 1, pageSize) with new filters, updates URL query parameters to reflect active filters for bookmarking/sharing, and displays filter summary chips below filter bar showing active filters with remove buttons.

- **resetActivityLogFilters()**: Clears all filter inputs by setting dateRange to last 7 days default, statusFilter to "all", recordTypeFilter to "all", operationTypeFilter to "all", searchQuery to empty string, removes filter chips, clears localStorage filter persistence, resets URL query parameters, calls fetchActivityLog() with default filters to reload unfiltered data, and displays info toast "Filters reset".

- **exportSyncLog()**: Opens ExportSyncLogModal with export configuration options, on user confirmation collects export parameters (dateRange, selectedColumns array, statusFilter, recordLimit, fileFormat), validates parameters (ensures at least one column selected, record limit is positive integer <= 10000), makes POST request to /api/salesforce/sync/export endpoint with payload: {dateRange, columns, filters, limit, format}, receives response with either downloadUrl for immediate download or jobId for async processing of large exports. If downloadUrl provided, triggers browser download using anchor element with download attribute. If jobId returned, polls /api/salesforce/sync/export/{jobId}/status endpoint every 5 seconds until status is "completed", then downloads file from provided URL. Shows progress indicator during export generation and displays success/error toast on completion.

- **downloadExportFile(downloadUrl, filename)**: Creates hidden anchor element with href set to downloadUrl, download attribute set to filename (format: "sync-log-{startDate}-{endDate}.{format}"), programmatically clicks anchor to trigger browser download, removes anchor element after 100ms, displays success toast "Export downloaded", and logs export event to analytics with logExportEvent(filename, fileSize).

- **retryFailedRecord(syncRecordId)**: Opens RetryFailedRecordModal showing original sync record data and error details, allows user to choose retry options (useOriginalSettings boolean, modifiedFieldMappings object, conflictResolution string), on confirmation makes POST request to /api/salesforce/sync/retry endpoint with payload: {syncRecordId, retryOptions, triggeredBy: currentUserId, triggeredAt: timestamp}. Receives newSyncJobId in response, displays info toast "Retry sync initiated", adds new activity log entry with status "pending", polls sync status for this specific record using pollRetryStatus(newSyncJobId, syncRecordId), and updates activity log table when retry completes (success or failure).

- **pollRetryStatus(syncJobId, syncRecordId)**: Makes GET request to /api/salesforce/sync/jobs/{syncJobId}/status endpoint every 3 seconds to check retry status. When job completes (status "completed" or "failed"), fetches updated sync record details with fetchSyncRecordDetails(syncRecordId), updates corresponding row in activity log table with new status, duration, and field changes, displays completion toast (success: "Contact synced successfully", error: "Retry failed: {errorMessage}"), stops polling, and if row was expanded, refreshes detail view with new data.

- **loadSyncStatistics(timeRange)**: Calls fetchSyncStatistics(timeRange) to retrieve aggregated metrics, processes response data to calculate derived metrics (error rate = failedSyncs / totalSyncs * 100, trend percentage by comparing with previous period), formats numbers for display (large numbers use K/M suffixes, percentages to 2 decimal places, durations as human-readable strings), determines visual indicators (trend arrows up/down, color coding for error rates: <1% green, 1-5% yellow, >5% red), updates SyncStatisticsCards with formatted data, renders mini sparkline charts for trend visualization if sufficient historical data exists, and caches statistics data for 5 minutes.

- **calculateErrorRate(successCount, failureCount)**: Computes error rate percentage as (failureCount / (successCount + failureCount)) * 100, handles division by zero (returns 0 if no syncs), rounds to 2 decimal places, determines health status threshold (healthy: <1%, degraded: 1-5%, critical: >5%), returns object with {percentage, status, color}. Used for sync health indicator color and error rate statistic card.

- **formatSyncDuration(milliseconds)**: Converts milliseconds to human-readable duration string by calculating hours, minutes, seconds from milliseconds value, formats as "2h 15m 30s" for long durations, "15m 30s" for medium durations, "30s" for short durations, or "< 1s" for very quick syncs. Handles null/undefined inputs by returning "N/A". Used for displaying sync duration in activity log and statistics cards.

- **formatRelativeTime(timestamp)**: Converts ISO timestamp to relative time string ("just now", "2 minutes ago", "3 hours ago", "yesterday", "3 days ago", "2 weeks ago") by calculating time difference between timestamp and current time, selecting appropriate unit (seconds/minutes/hours/days/weeks), applying pluralization rules, handling edge cases (future timestamps show "just now"). Updates dynamically with startAutoRefresh() polling for recent timestamps. Used for last sync time and activity log timestamps.

- **updateRelativeTimestamps()**: Iterates through all elements with class "relative-timestamp" on page, reads data-timestamp attribute containing ISO timestamp string, calls formatRelativeTime(timestamp) to generate updated relative time string, updates element textContent with new string, adds subtle fade animation on update to draw attention to changed values. Called by auto-refresh polling every 30 seconds to keep "X minutes ago" displays accurate.

- **renderSyncHealthIndicator(errorRate, lastSyncStatus)**: Determines health status dot color based on error rate thresholds and last sync status (healthy: green, degraded: yellow, critical: red, unknown: gray), creates status dot element with appropriate class and inline styles (width: 12px, height: 12px, border-radius: 50%, pulsing animation for active syncs), generates status text ("Healthy", "Degraded", "Critical", "Unknown"), attaches tooltip with detailed explanation ("Error rate: 0.5% - System is operating normally"), and renders into SyncStatusCard health indicator container.

- **renderActivityLogRow(syncRecord)**: Creates table row element for activity log with columns: timestamp cell (formatted as "Jan 15, 2025 2:30 PM" with relative time in tooltip), operation type cell (icon + badge with color coding: initial=blue, update=green, error=red, manual=purple), Salesforce ID cell (truncated with tooltip, clickable link to Salesforce record), Renzo contact name cell (clickable link to contact detail page), sync direction cell (→/←/↔ arrow icon), status cell (badge component with color and text), expand chevron cell (clickable icon, rotates on expand). Adds click handler to row for expansion, applies alternating row background colors, highlights error rows with red border, and appends row to tbody.

- **renderActivityLogDetailRow(detailData)**: Creates expandable detail row with colspan matching table columns, renders field changes section as sub-table with three columns (Field Name, Old Value, New Value), iterates through fieldChanges array to create row for each changed field, applies color coding (green for additions, yellow for modifications, red for deletions, orange for conflicts), displays null/empty value indicators as styled placeholder text ("-", "null", "empty"), renders sync metadata section with duration, retry count, error message (if failed) in formatted info boxes, adds action buttons container with "Retry Sync", "View Full Record", and "Report Issue" buttons, applies slide-down animation on render, and inserts detail row immediately after parent row in table.

- **renderFilterControlBar()**: Creates horizontal filter bar with flexbox layout containing: date range picker with preset buttons (Today, Last 7 Days, Last 30 Days, Custom) and custom date inputs (start date, end date), status multi-select dropdown using custom dropdown component with checkboxes for each status type, record type single-select dropdown, operation type filter checkboxes in collapsible section, search input with magnifying glass icon and clear button, "Apply Filters" primary button, "Reset Filters" secondary button. Attaches change handlers to all inputs that call applyActivityLogFilters() on Apply button click or Enter key press. Adds filter chips below bar showing active filters with remove buttons.

- **renderSyncStatisticsCards()**: Creates grid container with 4 stat card elements using CSS Grid (2x2 on desktop, 1x4 on mobile), renders each card with: icon (calendar for total syncs, clock for duration, alert for error rate, checkmark for last sync), primary metric value in large font (formatted with commas for thousands, "K" for thousands, "M" for millions), metric label in smaller secondary text, delta/trend indicator (percentage change from previous period with up/down arrow and color: green for positive, red for negative, gray for no change), mini sparkline chart if historical data available. Adds loading skeleton animation while data fetches.

- **renderErrorSummarySection()**: Creates collapsible section with header "Common Errors (Last 30 Days)" and collapse/expand toggle, renders error groups by iterating through commonErrors array from fetchSyncStatistics(), creates error group card for each error type showing: error type name/icon, count badge with number of occurrences, last occurrence timestamp in relative format, resolution suggestion text pulled from predefined error resolution database, "View Affected Records" link that applies filter to activity log showing only records with this error type. Groups errors by category (authentication, field mapping, validation, network, duplicate, permission) with category color coding. Displays "No errors detected" message with success icon if commonErrors array is empty.

- **renderExportSyncLogModal()**: Creates modal dialog with title "Export Sync Log", renders export configuration form with: date range section (preset buttons + custom inputs, default to current activity log filters), columns selection section with checkboxes for each available column (timestamp, operation type, Salesforce ID, contact name, status, duration, error message, field changes) with "Select All" toggle, status filter section matching main filter options, record limit input with validation (max 10000) and helpful text about large exports being processed asynchronously, file format radio buttons (CSV/JSON), estimated file size display that updates based on selections, cancel button, and "Download Report" primary button. Attaches form submission handler to call exportSyncLog() with collected parameters.

- **renderManualSyncModal()**: Creates modal dialog with title "Trigger Manual Sync" and warning icon, renders sync configuration form with: sync type radio buttons (Full Sync - all records, Incremental Sync - changes since last sync), sync direction dropdown (Bidirectional, To Salesforce Only, From Salesforce Only) with description text for each option, conflict resolution strategy dropdown (Newest Wins, Manual Review Required, Skip Conflicts) with implications of each choice, dry run checkbox with explanation text "Preview changes without applying them", warning callout box highlighting potential data overwrites, cancel button, and "Start Sync" primary button with loading spinner state. Attaches submission handler to call startManualSync() with form data.

- **renderRetryFailedRecordModal()**: Creates modal dialog showing original sync error details at top (error type, error message, timestamp), renders record preview section showing key fields from both Salesforce and Renzo contact (name, email, phone, company), displays original sync settings used, provides retry options form with: "Use original settings" radio button (default), "Modify field mappings" radio button with expandable field mapping interface, conflict resolution dropdown if applicable, checkbox to "Notify me when retry completes", cancel button, and "Retry Sync" primary button. Attaches handler to call retryFailedRecord() on submission.

- **renderSyncToastNotification(type, message, duration)**: Creates toast notification element with type-specific styling (success: green background, checkmark icon; error: red background, X icon; warning: yellow background, exclamation icon; info: blue background, info icon), sets message text, applies slide-in animation from top-right, appends to toast container (creates container if doesn't exist), auto-dismisses after specified duration (default 5000ms) using setTimeout(), adds manual close button with X icon, implements dismiss animation (slide-out), removes element from DOM after animation completes. Queues multiple toasts vertically with 10px spacing.

- **handleSyncCompletion(syncJobId, finalStatus)**: Called when active sync job completes (detected by checkActiveSyncStatus() returning completed status), stops auto-refresh with stopAutoRefresh(), fetches final sync statistics with fetchSyncStatistics(), updates activity log to show all new records from completed sync with fetchActivityLog(), updates SyncStatusCard with final status and timestamp, displays completion toast notification (success: "Sync completed: {recordCount} contacts updated", error: "Sync failed: {errorMessage}", warning: "Sync completed with {errorCount} errors - Click to view"), re-enables manual sync button, resets progress indicator, logs sync completion event to analytics with logSyncEvent(syncJobId, finalStatus, duration, recordCount), and if errors occurred, increments error badge count on Integrations nav item.

- **handleSyncError(syncJobId, errorDetails)**: Called when sync job fails with unrecoverable error, stops auto-refresh, updates SyncStatusCard to show error state (red health indicator, error message), displays error toast with retry option, logs error to error tracking service with logError('SyncError', {syncJobId, errorDetails, timestamp, userId}), creates error activity log entry with fetchActivityLog(), shows error resolution suggestions in ErrorSummarySection based on error type, and re-enables manual sync button after 5 second cooldown to prevent rapid retry attempts.
