- **Risk**: Inline `style.borderColor` may conflict with existing CSS transitions or :focus pseudo-class
- **Mitigation**: Use `!important` sparingly; test focus behavior after adding red borders
- **Watch for**: Focus state (green border) not overriding error state (red border)

### Field Reference Assumptions
- **Risk**: Task assumes field IDs (`#ctName`, `#ctEmail`, etc.) but actual IDs in full codebase may differ
- **Impact**: All selectors would fail, breaking all four fixes
- **Verify**: Actual contact form HTML structure before implementation

- **Risk**: Task requires "warning toast" for truncation, but no toast system visible in provided code

- **Options**: 
  - Use `alert()` as fallback (poor UX)

### Event Listener Timing
- **Risk**: Adding listeners before DOM elements exist will fail silently
- **Mitigation**: Wrap listener setup in DOMContentLoaded or ensure execution after form render

### Frequency Field Type Uncertainty

- **Impact**: Value setting approach may differ (`.value` vs `.selectedIndex`)
- **Verify**: Actual field type to ensure proper value assignment
