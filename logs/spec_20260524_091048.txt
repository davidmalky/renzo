# TECHNICAL SPECIFICATION: Full Mobile Responsive Layout Rework

## OVERVIEW
Implement comprehensive mobile-responsive layout transforming the desktop sidebar into a bottom navigation bar, adding a fixed top header, and optimizing all UI components for mobile viewports (≤768px). Includes mobile-specific card-based contact rendering, bottom-sheet modals, and touch-optimized interaction targets.

## VIEWS
- **Mobile Header** (#mobileHeader): Fixed top bar showing Renzo logo (left), username (center), logout icon (right). Visible only on mobile. Height 52px, z-index 500.
- **Bottom Navigation Bar** (.sidebar on mobile): Fixed bottom bar with horizontal navigation. 8 nav items with emoji icons and labels in column layout. Height 56px, z-index 500.
- **Mobile Contact Cards** (rendered in #contactsView): Card-based layout replacing table on mobile. Each card shows contact info with badges and action button.
- **Mobile Modals**: Bottom-sheet style modals aligned to viewport bottom with rounded top corners.

## FUNCTIONS
- **detectMobile()**: Returns true if window.innerWidth <= 768.
- **renderMobileContacts(contacts)**: Renders contact cards on mobile. For each contact: create card div with border-radius 12px, padding 16px, margin-bottom 10px. Display name with priority badge, company name, tier badge, status badge, and Message button. Return HTML string.
- **renderDesktopContactsTable(contacts)**: Existing table rendering logic extracted for desktop. Returns table HTML string.
- **updateContactsView()**: Modified to check detectMobile() and call appropriate render function. If mobile, render cards; else render table.
- **createMobileHeader()**: Generates mobile header HTML with logo, username from sidebar-user data, and logout button as ⚙️ icon.
- **initMobileLayout()**: Called on DOMContentLoaded and window resize. Shows/hides mobileHeader, adjusts .main padding, applies mobile nav styles based on viewport.
- **addEmojiToNavItems()**: Injects emoji icons before nav item text. Map: Dashboard=🏠, Contacts=👥, Queue=📤, Drafts=📝, Batch=⚡, Integrations=🔗, Activity=📊, Settings=⚙️.

## DATA
- **navEmojiMap**: Object mapping view names to emoji icons. Format: {dashboard: "🏠", contacts: "👥", queue: "📤", drafts: "📝", batch: "⚡", integrations: "🔗", activity: "📊", settings: "⚙️"}.
- **mobileBreakpoint**: Constant 768 (pixels).
- **currentUser**: Username string from .sidebar-user element textContent.

## API
No external API calls required. All changes are CSS and DOM manipulation.

## ERRORS
- **Viewport Detection Failure**: If window.innerWidth undefined, default to desktop layout. Catch error in detectMobile(), return false.
- **Missing Contact Data**: If contact properties missing (name, company, tier, status), render placeholder "—" and hide missing badge.
- **Render Function Not Found**: If renderContacts() doesn't exist, wrap new logic in try-catch. Log error, show empty state.
- **Mobile Header User Missing**: If .sidebar-user not found, display "User" as fallback text.
- **Resize Event Throttle**: Debounce window resize listener to prevent excessive re-renders. Use 150ms delay.
- **Nav Item Emoji Mapping Failure**: If view name not in navEmojiMap, skip emoji, show text only.
- **Modal Overflow**: If modal content exceeds 90vh, ensure scrollable modal-body with overflow-y auto.
