## RISKS:

### Technical Conflicts
1. **No drag-drop library** - Task requires drag-to-reorder but no existing drag-drop implementation or library (SortableJS, DragDropTouch, etc.) found in codebase
2. **No form validation framework** - Real-time validation needs custom implementation
3. **No state management** - Complex form state (mappings array, validation errors, preview data) needs management without framework
4. **No API layer visible** - Cannot confirm Salesforce metadata API or Renzo schema API exists
5. **Database schema unknown** - `field_mappings` table structure specified but no ORM or database layer visible in frontend code

### Data Structure Conflicts
6. **localStorage usage unclear** - No localStorage keys found in provided code; unclear if mappings should persist client-side or server-side
7. **Data type enumeration** - No existing field type system; need to define supported types (text, date, number, email, phone, etc.)
8. **Transformation rules format** - JSON structure for transformation_rules column undefined

### UX/Accessibility Risks
9. **Drag-drop accessibility** - Keyboard navigation for reordering not typically accessible without ARIA implementation
10. **Real-time validation performance** - Validating on every keystroke with API calls could cause performance issues
11. **Preview data fetching** - Real-time preview may require rate limiting or debouncing

### Integration Risks
12. **Salesforce API rate limits** - Field metadata fetching may hit API limits if done repeatedly
13. **Bidirectional sync conflicts** - Conflict resolution logic not defined; risk of data loss
14. **Migration impact** - "Show which contacts will be affected" requires contact counting/analysis system
15. **JSON export schema** - Import validation needed to prevent corrupt configurations

### Scope Creep Risks
16. **Transformation options complexity** - "Trim whitespace, format phone, default values" could expand infinitely (case conversion, concatenation, splitting, regex, etc.)
17. **Field metadata caching** - No caching strategy defined; repeated metadata fetches inefficient
18. **Versioning** - No version control for mapping configurations; rollback capability undefined
