## RISKS:

- **Data Migration**: Existing contacts in localStorage won't have the three new fields (contractExpiry, invoiceAmount, lastContactDate) - need default values or null handling
- **Date Format Inconsistency**: Existing 'lastContact' field format may conflict with new 'lastContactDate' - need to verify format compatibility
- **Null/Undefined Handling**: `computePriorityScore()` must handle missing field values gracefully (e.g., contacts without contractExpiry)
- **Sort Performance**: Adding priority calculation and sorting to every render could impact performance with large contact lists
- **Visual Clutter**: Adding priority badge next to tier badge may create crowded UI - need careful placement
- **Breaking Changes**: Modifying `renderContacts()` signature or behavior could break other code that calls it
- **AI Prompt Length**: Including outreach trigger in `generateAiMessage()` prompt could exceed token limits or change message quality
- **Division by Zero**: Priority score formula uses division - need safe math operations
- **Date Math**: Computing daysSince and contract expiry urgency requires robust date parsing
- **localStorage Limits**: Adding three fields per contact increases storage size

**Priority Score Algorithm:**
- Returns: 0-100 (number)
- Formula: `(min(daysSince/90, 1) * 40) + (contractExpiryUrgency * 30) + (min(invoiceAmount/10000, 1) * 30)`
- Components:
  - Days since last contact component: max 40 points (caps at 90 days)
  - Contract expiry urgency component: max 30 points
  - Invoice amount component: max 30 points (caps at $10,000)

**Outreach Trigger Return Values:**
- Returns: string (most urgent trigger)
- Options:
  - "Contract expires in X days"
  - "Invoice $X outstanding"
  - "Not contacted in X days"

**Priority Score Badge Thresholds:**
- 80+: Red (high priority) - use --error or --priority-high
- 50-79: Amber (medium priority) - use --warning or --priority-medium  
- <50: Green (low priority) - use --success or --priority-low
