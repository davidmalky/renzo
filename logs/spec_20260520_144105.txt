# TECHNICAL SPECIFICATION: BATCH OUTREACH AND TRAINABLE INSTRUCTIONS

## OVERVIEW
Add batch outreach capability and trainable instructions to existing Renzo app. Batch outreach allows natural language queries to filter contacts and generate AI messages in bulk. Trainable instructions let users define custom rules that modify AI message generation behavior. All existing functionality remains unchanged.

## VIEWS

**BatchOutreachView**
- Main heading "Batch Outreach"
- Instructional text explaining natural language query format with examples
- Large textarea (id: batchPromptInput) for natural language prompt input
- Generate button (id: generateBatchBtn) 
- Progress section (id: batchProgress, hidden by default) showing "Generating X of Y..." with animated indicator
- Results section (id: batchResults, hidden by default) showing completion summary with count of messages generated and added to queue
- Error display area for validation messages

**SettingsView (enhanced)**
- Existing sections remain unchanged
- New section "My Outreach Rules" after API key section
- Section contains: heading, description text, textarea (id: newRuleInput) for rule entry, "Add Rule" button (id: addRuleBtn)
- Rules list container (id: rulesList) showing each rule as a card with rule text and delete button
- Empty state message when no rules exist

## FUNCTIONS

**showBatchOutreach()**
- Hides all other views
- Shows batch outreach view container
- Updates active nav state to highlight Batch Outreach
- Clears previous batch results and progress
- Focuses on prompt textarea

**parseBatchPrompt(promptText)**
- Converts promptText to lowercase for matching
- Initializes filters object with fields: hasContractExpiry, hasInvoice, hasLastContact
- Checks for keywords: 'contract'/'expiry'/'expire' sets hasContractExpiry=true
- Checks for keywords: 'invoice'/'overdue'/'unpaid' sets hasInvoice=true
- Checks for keywords: 'not contacted'/'no contact'/'haven\'t contacted' sets hasLastContact=true
- Returns filters object

**filterContactsByPrompt(contacts, filters)**
- Iterates through contacts array
- For each contact, checks if it matches ALL active filters
- If hasContractExpiry=true: contact must have contractExpiry field with non-empty value
- If hasInvoice=true: contact must have invoiceAmount > 0
- If hasLastContact=true: contact must have lastContactDate that is null/empty OR older than 30 days
- Returns array of matching contacts

**generateBatchMessages(contacts)**
- Async function that processes contacts sequentially
- Shows progress section, hides results
- For each contact (index i): updates progress text "Generating {i+1} of {contacts.length}..."
- Calls existing generateAiMessage(contact) with rules appended
- Waits for completion before next contact
- Catches errors per contact, logs but continues to next
- Collects all successful message results in array
- After all complete: calls addBatchToQueue(results)
- Hides progress, shows results section with summary
- Returns count of successful generations

**addBatchToQueue(messages)**
- Retrieves existing outreach queue from localStorage ('renzo_queue')
- Appends all messages from array to queue
- Saves updated queue back to localStorage
- Triggers queue count badge update in UI

**loadRules()**
- Retrieves rules array from localStorage key 'renzo_rules'
- If not exists, returns empty array
- Parses JSON and returns array of rule strings

**saveRules(rulesArray)**
- Converts rulesArray to JSON
- Saves to localStorage key 'renzo_rules'
- Returns true on success

**renderRulesList()**
- Calls loadRules() to get current rules
- Clears rulesList container
- If rules.length === 0: shows empty state message "No rules yet. Add your first rule above."
- For each rule: creates rule card div with rule text and delete button (data-rule-index attribute)
- Appends all cards to rulesList container

**addRule()**
- Gets value from newRuleInput textarea
- Trims whitespace
- Validates: must be 10-500 characters, shows error if invalid
- Calls loadRules(), appends new rule to array
- Calls saveRules() with updated array
- Clears textarea
- Calls renderRulesList() to update display
- Shows success alert "Rule added successfully"

**deleteRule(index)**
- Calls loadRules() to get current rules
- Removes rule at specified index using splice()
- Calls saveRules() with updated array
- Calls renderRulesList() to refresh display
- Shows success alert "Rule deleted"

**getRulesPromptAddition()**
- Calls loadRules() to get rules array
- If empty: returns empty string
- Constructs string: "\n\nFollow these custom rules: " + rules.join('; ')
- Returns constructed string

**generateAiMessage(contact) [MODIFIED]**
- Existing function modified minimally
- Before sending to OpenAI API: calls getRulesPromptAddition()
- Appends rules string to the system prompt or user message
- All other logic remains identical

**initBatchOutreach()**
- Attaches click handler to generateBatchBtn
- Handler: gets prompt text, validates not empty, calls parseBatchPrompt(), filters contacts, validates matches found, calls generateBatchMessages()
- Validates API key exists before processing

**initRulesManagement()**
- Calls renderRulesList() on load
- Attaches click handler to addRuleBtn calling addRule()
- Attaches delegated click handler to rulesList for delete buttons using event.target matching

## DATA

**renzo_rules (localStorage)**
- Array of strings, each string is one custom rule
- Format: ["Rule text 1", "Rule text 2", ...]
- Persists between sessions

**batchState (runtime variable)**
- Object tracking current batch operation
- Fields: isGenerating (boolean), currentIndex (number), totalCount (number), results (array)
- Reset at start of each batch operation

## API

**OpenAI API (existing, modified calls)**
- Endpoint: https://api.openai.com/v1/chat/completions
- Method: POST
- Modified payload: system or user message now includes rules via getRulesPromptAddition()
- Original message structure + rules appended as text
- Response handling unchanged

## ERRORS

**Batch Outreach Errors**
- Empty prompt: "Please enter a search query" - red text below textarea
- No API key: "Please add your OpenAI API key in Settings" - alert modal
- No matches found: "No contacts match your query. Try different keywords." - warning background alert in results area
- API failure during batch: Log error, skip contact, continue with next. Show warning in summary "X of Y messages generated successfully"
- Network timeout: "Network error. Please check connection and try again." - error alert

**Rules Management Errors**
- Empty rule: "Rule cannot be empty" - red text below textarea
- Rule too short (<10 chars): "Rule must be at least 10 characters" - red text
- Rule too long (>500 chars): "Rule must be under 500 characters" - red text
- localStorage full: "Unable to save rule. Storage limit reached." - error alert
- Invalid JSON parse: Silent fail, return empty array, log to console
