## RISKS:

### Technical Conflicts
1. **Nested Modals**: Expression builder modal opening inside mapping modal may conflict with `.modal-overlay` z-index and body scroll lock
2. **Event Bubbling**: Click handlers on mapping cards vs. expression edit buttons may conflict
3. **Performance**: Real-time expression evaluation on large datasets (500+ records) may cause UI lag
4. **Memory**: Storing transformation results for every record with step-by-step data could exceed localStorage limits

### Layout Issues
1. **Sidebar Width**: Adding 300-400px function library sidebar may break responsive design on 1366px screens
2. **Modal Size**: Expression builder needs 90vh+ height, may conflict with existing modal constraints
3. **Table Width**: Adding "Transformed Value" column to records table may cause horizontal scroll issues

### State Management
1. **Tab Switching**: Expression changes in builder need to persist when switching between Setup/Mapping/Results tabs
2. **Draft Expressions**: User may start editing expression but not save—needs draft state handling
3. **Multiple Expression Editors**: User opens expression builder, then clicks different field—needs cleanup logic

### JavaScript Security
1. **Custom Function Sandbox**: `eval()` or `Function()` constructor poses XSS risk—needs proper sandboxing
2. **Infinite Loops**: User-defined functions could contain while(true)—needs execution timeout
3. **Prototype Pollution**: User expressions accessing `__proto__` or `constructor` could break app

### Data Integrity
1. **Expression Serialization**: Complex nested functions may not serialize properly to localStorage JSON
2. **Function Version Conflicts**: Saved expressions using old function signatures after updates
3. **Type Coercion Edge Cases**: "123" + 456 = "123456" vs 579 depending on context

### Browser Compatibility
1. **Drag-and-Drop**: Function chip dragging may not work consistently across browsers
2. **Syntax Highlighting**: Custom implementation may be slow; libraries add 50KB+ bundle size
3. **Modal Scrolling**: iOS Safari has known issues with `position: fixed` inside scrolling containers
