# TECHNICAL SPECIFICATION: Smart Priority Scoring for Renzo CRM

## OVERVIEW
Add intelligent priority scoring to the existing Renzo CRM contacts system based on contract expiry dates, outstanding invoices, and last contact timing. The system will compute a 0-100 priority score, display it visually on contact rows, auto-sort contacts by priority, and integrate trigger reasons into AI message generation. All existing functionality remains unchanged.

## VIEWS

- Add three new form groups after existing fields, before the submit button
- **Contract Expiry Field**: form-group containing label "Contract Expiry" + date input (id="contactContractExpiry", class="form-input")
- **Invoice Amount Field**: form-group containing label "Outstanding Invoice $" + number input (id="contactInvoiceAmount", class="form-input", min="0", step="0.01")
- **Last Contact Date Field**: form-group containing label "Last Contact Date" + date input (id="contactLastContactDate", class="form-input")

## FUNCTIONS

### computePriorityScore(contact)
**Purpose**: Calculate 0-100 priority score from contact data
**Parameters**: contact object with contractExpiry, invoiceAmount, lastContactDate fields
**Returns**: Integer 0-100

**Steps**:
1. Initialize score = 0
2. **Last Contact Scoring** (max 40 points):
   - If lastContactDate exists: calculate daysSince = (today - lastContactDate) / milliseconds per day
   - Add min(daysSince / 90, 1) * 40 to score
   - If no lastContactDate: add 0 points
3. **Contract Expiry Scoring** (max 30 points):
   - If contractExpiry exists: calculate daysUntil = (contractExpiry - today) / milliseconds per day
   - If daysUntil <= 90 and daysUntil > 0: add (1 - daysUntil/90) * 30 to score
   - If daysUntil <= 0 (expired): add 30 points
   - If no contractExpiry or > 90 days away: add 0 points
4. **Invoice Scoring** (max 30 points):
   - If invoiceAmount exists and > 0: add min(invoiceAmount / 10000, 1) * 30 to score
   - If no invoiceAmount or 0: add 0 points
5. Return Math.round(score)

### computeOutreachTrigger(contact)
**Purpose**: Determine most urgent outreach reason
**Parameters**: contact object
**Returns**: String describing trigger reason

**Steps**:
1. **Check Contract Expiry First** (highest priority):
   - If contractExpiry exists: calculate daysUntil
   - If daysUntil <= 90 and daysUntil > 0: return "Contract expires in [X] days"
   - If daysUntil <= 0: return "Contract expired [X] days ago" (use absolute value)
2. **Check Invoice Second**:
   - If invoiceAmount exists and > 0: return "Invoice $[X,XXX] outstanding" (format with commas)
3. **Check Last Contact Third**:
   - If lastContactDate exists: calculate daysSince
   - If daysSince > 0: return "Not contacted in [X] days"
4. **Fallback**: If none exist, return "New contact - establish relationship"

### renderContactRow(contact) - MODIFY EXISTING
**Modification**: Insert priority score badge after contact name
**Steps**:
1. Keep all existing row rendering logic
2. After creating contact name element, call computePriorityScore(contact)
3. Create score badge span: class="priority-score-badge" + color class based on score
4. Determine color class: score >= 80 → "score-high", score >= 50 → "score-medium", else "score-low"
5. Set badge innerHTML to score number
6. Insert badge into row after name, before existing priority badge
7. Continue with existing rendering

### displayContacts() - MODIFY EXISTING
**Modification**: Sort contacts by priority score descending before rendering
**Steps**:
1. Get contacts array from localStorage (existing)
2. **NEW**: Map contacts to include computed score: contacts.map(c => ({...c, _computedScore: computePriorityScore(c)}))
3. **NEW**: Sort by _computedScore descending: sort((a,b) => b._computedScore - a._computedScore)
4. Continue with existing loop to render each contact row
5. Keep all existing rendering logic

## ERRORS

### Missing Field Handling
- If new fields empty when computing score: treat as 0 contribution (no error)
- If date fields contain invalid dates: treat as empty, score = 0 for that component

### Date Calculation Errors
- Wrap date math in try-catch: if Date parsing fails, default to 0 days
- Invalid date strings: return 0 contribution to score

### Score Display Errors
- If computePriorityScore returns NaN: default to 0, show with score-low class
- If contact object missing: skip score badge rendering, log warning to console

### API Prompt Error
- If computeOutreachTrigger fails: use fallback "General follow-up needed"
- If trigger computation throws: catch error, continue with existing prompt without trigger

### Sort Failure
- If score computation fails during sort: wrap in try-catch, place failed contacts at end
- If _computedScore is NaN: treat as 0 for sorting purposes

### Form Validation
- No required validation on new fields (all optional)
- If invoiceAmount negative: Math.abs() to positive before saving
- If date fields have future dates where past expected: allow but may result in unusual scores (acceptable)
